## 이 폴더의 규칙
- **한 단원 = 「기초 개념」 + 「심화」 2단**으로 쌓는다(1-1이 기본 14 + 심화 10으로 먼저 그렇게 되어 있다).
  기초는 개념·용어를 그림 없이 묻고, 심화는 자료·그림·계산을 묻는다.
- 선택지 **4개**, 정답 표시는 **★**, 해설은 **존댓말**(2026-08-18 교사 결정).
- 각 문항 끝에 `*(무엇을 묻는 문항인가: …)*` 한 줄을 단다 — 나중에 중복 대조와 이원목적분류에 쓴다.
- 정답 번호가 한쪽으로 쏠리지 않게 ①~④를 고르게 배치하고, 파일 끝 「제작 기록」에 분포를 적는다.
- 문항·해설의 진술은 **교과서 본문에 근거가 있는 것만** 쓴다. 읽기자료·심화 상자에서 가져올 때는 그렇다고 밝힌다.

## 올리는 법 (md → 라이브)
문항 md는 사람이 읽는 원문이고, **라이브에 올라가는 것은 조립기가 만든 객체**다. 손으로 admin에 옮겨 적지 않는다.

| 단계 | 명령 |
|---|---|
| 1. 검사 | `node "생물의 유전/활동/_build_퀴즈기초_1-2_1-3.js"` → 277단언 |
| 2. 라이브 상태 확인(쓰기 없음) | `node "생물의 유전/활동/_seed_퀴즈기초.js"` |
| 3. 실제로 올리기 | `node "생물의 유전/활동/_seed_퀴즈기초.js" --write` |

- 3번은 **quizBackups/ 에 통째로 백업한 뒤** `quizzes/<id>` · `quizMeta/<id>` 를 PUT 하고, 키를 정렬해 깊은 비교로 재검증한다.
- 기존 퀴즈는 id 가 겹치면 **스크립트가 멈춘다**(덮어쓰지 않는다).
- 학교망이 TLS 검사 프록시라 실패하면 앞에 `NODE_TLS_REJECT_UNAUTHORIZED=0` 을 붙일 것.
- ★올린 뒤 **위첨자(Iᴬ Iᴮ Xᴿ Xʳ)가 화면에서 깨지지 않는지 눈으로 확인**할 것.
  같은 문자가 라이브 1-2 심화에 2026-08-20부터 들어가 있으므로 렌더 실적은 있다.
