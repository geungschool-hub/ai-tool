# 작업노트 (USB 동반 메모리)

이 폴더는 **USB(`AI tool` 폴더)와 함께 다니는 메모리**입니다. 어느 PC에서 작업하든 `CLAUDE.md`가 이 폴더를 가리키므로, Claude가 관련 작업 시 해당 파일을 읽고 맥락을 이어갑니다.

- 자동 로드되는 진입점은 `..\CLAUDE.md` 입니다. **노트 목록 정본은 이 README 하나** — 새 메모를 추가하면 여기에만 한 줄 등록하면 됩니다(CLAUDE.md는 이 파일을 가리키기만 함).
- ★**학생 실명·학번을 노트 본문에 쓰지 말 것.** 이 폴더는 PUBLIC 저장소에 추적됩니다. 실명이 필요한 대조표는 gitignore된 데이터 폴더(`생명과학 세특/_판독/` 등)에 두고 노트에는 경로만 적을 것.
- PC에 묶인 Claude 자동 메모리(`C:\Users\...\.claude\...`)와 달리, 여기 파일들은 USB로 옮겨도 그대로 읽힙니다.
