# 작업노트 (USB 동반 메모리)

이 폴더는 **USB(`AI tool` 폴더)와 함께 다니는 메모리**입니다. 어느 PC에서 작업하든 `CLAUDE.md`가 이 폴더를 가리키므로, Claude가 관련 작업 시 해당 파일을 읽고 맥락을 이어갑니다.

- 자동 로드되는 진입점은 `..\CLAUDE.md` 입니다. **노트 목록 정본은 이 README 하나** — 새 메모를 추가하면 여기에만 한 줄 등록하면 됩니다(CLAUDE.md는 이 파일을 가리키기만 함).
- ★**학생 실명·학번을 노트 본문에 쓰지 말 것.** 이 폴더는 PUBLIC 저장소에 추적됩니다. 실명이 필요한 대조표는 gitignore된 데이터 폴더(`생명과학 세특/_판독/` 등)에 두고 노트에는 경로만 적을 것.
  커밋 전 `python _노트_실명점검.py` (2·3학년 학번꼴 + 명단 170명 대조).
- PC에 묶인 Claude 자동 메모리(`C:\Users\...\.claude\...`)와 달리, 여기 파일들은 USB로 옮겨도 그대로 읽힙니다.

## 상태 표시 읽는 법
| 표시 | 뜻 |
|---|---|
| 🟢 | **지금 하고 있는 일.** 이번 학기에 계속 손댄다 |
| ⚪ | **만들어 두고 쓰는 것.** 평소엔 안 건드리지만 살아 있다(내년 재사용 포함) |
| 📦 | **끝난 일의 기록.** 새로 쓸 일은 없고 "그때 왜 그랬나"를 찾을 때만 |
| 🔧 | **방법·정책.** 특정 갈래가 아니라 어느 작업에나 적용된다 |

> ★2026-08-18 정리: 갈래별로 나누고 상태를 붙였습니다. 같은 대상을 다루던 노트 5쌍을 합쳤고, 낡은 노트 3개를 지웠습니다.

### `[[이런 링크]]`에 대하여
노트 안의 `[[이름]]`은 **둘 중 하나**를 가리킵니다.
① 이 폴더의 다른 노트(예: `[[방법모음_문서추출과판독]]`) — 항상 열립니다.
② **PC에 묶인 Claude 자동 메모리** — USB를 다른 PC에 꽂으면 **없을 수 있습니다.**
지금 남아 있는 것은 `commit-only-on-request`·`activity-tone-formal` 둘뿐이고,
`feedback_*`·`ref_*` 로 시작하는 링크(보고서작성법·융과탐 노트에 5건)는 **옛 메모리라 이미 사라졌습니다** — 못 찾아도 정상입니다.
