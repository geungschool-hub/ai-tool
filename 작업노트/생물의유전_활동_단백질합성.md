## 무엇을 하는 활동인가
2단계 **전사**(주형 DNA 30칸 → mRNA 직접 채우기, T 단추는 「RNA에는 타이민이 없다 → 유라실」로 오개념 교정) →
3단계 **번역**(E·P·A 라이보솜 · tRNA 카드 9장 · [🔗 펩타이드결합 만들고 라이보솜 이동] · 종결코돈에서 「결합할 tRNA가 없다」 발견) →
4단계 **정리하기**(탐구 과정 ①~⑧을 전사/번역/**해당 없음**으로 분류·채점) → 💡 **돌연변이 5종**을 학생이 찾아내는 확장.

## ★이 활동의 핵심 설계 — 「앱이 답을 알려 주면 성취기준이 죽는다」
**12유전02-02는 「유전 부호 표를 사용하여 해독」이다.** 초판은 코돈의 아미노산과 필요한 안티코돈을 앱이 먼저 알려 줘,
학생이 **코돈표를 한 번도 안 보고 카드 글자만 대조해** 활동을 끝낼 수 있었다(검토자 2명이 독립적으로 「중대」로 지목). 2026-08-14에 셋을 막았다.

| 어디 | 어떻게 |
|---|---|
| `#ctNow` | 도킹 전에는 **코돈만** + 표를 읽는 길(왼쪽 세로축 G → 위쪽 가로축 U → 오른쪽 세로축 A). 아미노산은 감춤 |
| 코돈표 칸 강조 | **강조 자체가 정답 공개**다(칸에 코돈이 병기돼 있으므로) → 해독 뒤에만 `.cur` |
| ⑤ 프롬프트 | 안티코돈 문자열 제거, 「염기쌍을 이루는 안티코돈을 가진 카드를 찾아 탭!」까지만 |

**공개 시점 = 도킹 성공 후 · 종결코돈 판정 · 번역 완료**, 그리고 못 찾는 학생을 위한 탈출구 **[💡 아미노산 확인하기]**
(`showCodonHint` → `state.hintCodon`·`hintUsed` 저장 · 누른 코돈에만 적용). 구현은 `highlightCodon(codon, reveal)`의 두 번째 인자로 갈린다.
**오답 피드백에서는 정답 안티코돈을 알려 준다** — 틀린 뒤의 안내는 학습을 돕지 우회로가 되지 않는다.

## 다른 설계 판단
- **코돈표는 교과서 62쪽과 같은 구조여야 한다** — 칸마다 `UUU 페닐알라닌`처럼 **코돈 병기**, thead에 **세 축 이름**(첫 번째/두 번째/세 번째 염기).
  아미노산 이름만 있으면 표를 '읽는' 연습이 되지 않는다. 표가 넓어지므로 `min-width:880px` + `.ctab-outer` 가로 스크롤.
- **정리하기 1의 ①은 「해당 없음」** — 교과서 정답이 전사=②, 번역=③~⑧이라 ①(모형 오리기)은 어느 쪽도 아니다. 3분류로 두자 가장 변별력 있는 문항이 됐다.
- **교과서 ⑥을 한 동작으로 묶지 않았다** — 도킹(⑤)과 [결합+이동](⑥⑦)을 두 번의 조작으로 나눠 순서를 몸으로 익히게 함.
- **자동 번역은 종결 직전까지만** — 「종결코돈에는 붙을 tRNA가 없다」는 이 활동의 결론이라 학생이 직접 눌러야 한다.
- 안티코돈 표기는 부록 카드 그대로(염기별 상보 치환) 쓰되, **역평행이라 3′→5′로 읽은 것**이라는 설명을 화면 주석과 코드 주석에 남겼다.

## 검토에서 잡힌 것 (전문 = `생물의 유전/활동/_검토결과_20260813.md`)
- **[치명] 개시코돈이 파괴돼도 완전한 폴리펩타이드를 그렸다** — 판정 문구는 「번역이 시작되지 않는다」인데 그림은 아미노산 9개.
  학생은 문구보다 그림을 믿는다. → `startlost`면 `mutPeptide=[]`.
- **[중대] 전사만 끝내도 정리하기 3의 정답이 통째로 공개**(`&&`가 `||`여야 했다) — 자동 전사 30초면 번역을 통째로 우회할 수 있었다.
- **[중대] 「전사 다시 하기」가 번역 상태를 안 지워** 잠금·진행 배지가 어긋난 채 저장까지 됐다 → `resetTranslation()` 분리 + `normalizeState` 방어선.
- **[중대] 돌연변이 시트가 원본 기준으로 「현재 C」**라고 말해 화면에 보이는 A와 어긋났다 → 「지금(mutSeq) / 원래(MRNA_KEY)」 분리.
- 그 밖에: 펩타이드결합 모범답안의 「물 한 분자가 빠지며」 삭제(라이보솜의 펩타이드 전달 반응은 탈수축합이 아니고 교과서도 안 다룬다),
  타일 탭 영역 30→42px, 판정 카드 이모지↔테두리 색 일치, 11열 대조표 가로 스크롤.
