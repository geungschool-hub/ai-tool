- 실제 화면 배치·터치감은 교사가 직접 확인하기로 함.

## 이후 개선 (2026-08-12, 교사 피드백 4건 — 전부 배포·라이브 확인 완료)
1. **막대 이름표**: 뽑기 버튼 위에 「빨간/파란/노란 막대」 캡션(`.slot-cap`, 막대 색 글자).
2. **탄생 연출**: 결과 박스 팝인(`@keyframes pop`) + 👧/👦 54px 바운스 + 색종이 10조각(1.5초 내 종료·자동 제거). 문구 「딸/아들이 태어났다!」 24px.
3. **기록표 부모 행 음영**: `#EAF0F7` + 어머니 행 아래 진한 구분선 → 자녀 행(흰색)과 구분.
4. **★부모 유전자형 바꾸기 패널**(실험 규칙 우측, 좁은 화면에선 아래로): 어머니 (가)(나) 3택·(다) XᴰXᴰ/XᴰXᵈ/XᵈXᵈ, 아버지 (다) XᴰY/XᵈY. 「교과서 기본값으로」 버튼.
   - 구조: `parents` 상태 → `rebuildCups()`로 컵 파생. 딸의 아버지 X 대립유전자도 뽑힌 막대(`'X'+대립유전자`)에서 동적으로 상속.
   - **변경 시 뽑기·기록 전면 초기화**(`resetFamily()`) — 부모가 바뀌었는데 이전 자녀가 남으면 모순이라 의도한 설계.
   - 정리하기 모범답안 2개에 「(교과서 기본 유전자형 기준)」 표시 추가(바꾼 상태에서 읽으면 어긋나므로).
   - 「다시 하기」= 유전자형도 기본값 복원.

## 2026-08-14 — 가상 자녀 시뮬레이션 100명 → **10,000명** (배포 완료)
- 교사 지시. `runSim()`의 `N`만 늘린 게 아니라 표기도 함께: 인원 **천단위 쉼표**(`comma()` 신설), 발현 비율 **소수 1자리**
  (10,000명이면 성별당 ~5,000명이라 정수 %로는 수렴 관찰이 뭉개진다). 문항 제목·버튼 문구도 「10,000명」으로.
- 헤드리스 24단언 통과 — 합계 10,000 · 성비 45~55% · **이론값 수렴**(교과서 기본값에서 (가) 딸·아들 ≈75%, (다) ≈50%) ·
  부모 유전자형 변경 후에도 성립(어머니 XᴰXᴰ → (다) 100%, 열성 모드 → 0명) · 계산 400ms 미만.
- 배포: gene-sim `bf8e38a` push → 라이브 curl 200·**로컬 원본과 바이트 일치**. ★이 PC에서 curl은 `--ssl-no-revoke` 필수.
  ★Pages 반영에 시간이 걸린다 — push 직후 curl은 옛 바이트(31116)를 준다. 크기·문자열로 확인할 것.

## 🟡 아직 안 고친 것 (2026-08-14 읽으며 발견, 교사 미지시)
1. **모범답안이 아무 때나 열린다** — 뽑기·서술 없이 정리하기 3문항 답을 볼 수 있다.
   단백질합성에서 「앱이 답을 미리 알려 주던 곳」으로 잡아 막았던 그 패턴이 여기 그대로 남아 있다.
2. **100명(→10,000명) 표 아래 고정 문구가 거짓이 될 수 있다** — 「(다)의 발현 비율은 성별에 따라 다르다」고 단언하는데,
   부모 유전자형을 바꾸면(예: 어머니 XᴰXᴰ) 딸·아들 모두 100%가 되어 문장과 어긋난다. 문구를 현재 설정에서 파생시켜야 한다.
3. **저장/복원 없음** — 새로고침하면 기록·서술 textarea가 전부 날아간다(태블릿 수업에서 실제로 터지는 자리).
4. **헤드리스 테스트 파일이 레포에 없다** — 다른 3종은 `_test_*.js`가 있는데 1-1만 없다(이번 검증은 임시 스크립트로 했다).
