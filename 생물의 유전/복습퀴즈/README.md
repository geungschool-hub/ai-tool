## 이 폴더의 규칙
- **한 단원 = 「기초 개념」 + 「심화」 2단**으로 쌓는다(1-1이 기본 14 + 심화 10으로 먼저 그렇게 되어 있다).
  기초는 개념·용어를 그림 없이 묻고, 심화는 자료·그림·계산을 묻는다.
- 선택지 **4개**, 정답 표시는 **★**, 해설은 **존댓말**(2026-08-18 교사 결정).
- 각 문항 끝에 `*(무엇을 묻는 문항인가: …)*` 한 줄을 단다 — 나중에 중복 대조와 이원목적분류에 쓴다.
- 정답 번호가 한쪽으로 쏠리지 않게 ①~④를 고르게 배치하고, 파일 끝 「제작 기록」에 분포를 적는다.
- 문항·해설의 진술은 **교과서 본문에 근거가 있는 것만** 쓴다. 읽기자료·심화 상자에서 가져올 때는 그렇다고 밝힌다.
