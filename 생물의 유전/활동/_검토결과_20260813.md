교과서 정답은 전사=②, 번역=③~⑧이므로 **①(모형 오려 내기)은 어느 쪽도 아니다.** 두 분류만 주면 ①을 억지로 넣게 되므로 「해당 없음」을 세 번째 상태로 추가했고, 이 항목이 가장 변별력 있는 문항이 되었다(오답 시 「①은 준비 과정」 피드백).

- **수정 방법**: 모형의 9종을 먼저 고유 배정하고 나머지는 기존 방식으로.
```js
function buildAaHue(){
  var h = {}, n = 0;
  for (var i=0;i<TRNA_CARDS.length;i++) h[TRNA_CARDS[i].aa] = n++;   // 모형 9종 → a0~a8 고유
  for (var j=0;j<CODON_GROUPS.length;j++){
    var nm = CODON_GROUPS[j][0];
    if (h[nm] === undefined) h[nm] = j % 9;                           // 돌연변이로 등장하는 나머지
  }
  return h;
}
```
기존 테스트(`/^a[0-8]$/`, `aaClass('없는아미노산')==='a8'`)는 그대로 통과한다. 테스트에 `new Set(S.PEPTIDE_KEY.map(S.aaClass)).size === 9` 1줄 추가.

- **위치**: 섹션 제목 ①~④(388·407·456·505행)와 STEP_TEXT ①~⑧(661~670행)·정리하기 1 표
- **문제**: 앱의 섹션 번호 ①②③④(중심원리·전사·번역·정리하기)와 교과서 탐구 과정 번호 ①~⑧이 같은 원문자를 쓴다. 정리하기 1이 "②는 전사, ③~⑧은 번역"을 묻는데, 화면 위쪽에서 ②는 '전사 섹션', ③은 '번역 섹션'이라 우연히 겹쳐 보이므로 학생이 무엇을 분류하는지 헷갈린다.
- **수정 방법**: 섹션 제목을 '1단계 중심원리 / 2단계 전사 / 3단계 번역 / 4단계 정리하기'처럼 아라비아 숫자로 바꾸고, 원문자 ①~⑧은 교과서 탐구 과정에만 쓴다.

### [경미] 13. 태블릿 사용성(프로젝트 규칙)
