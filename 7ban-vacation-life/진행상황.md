## 🔴 반드시 먼저 처리 — 가입·로그인이 깨져 있었음 (원인 규명 + 코드 수정 완료, **DB 재실행 필요**)

`login` RPC를 실제로 호출해 확인한 에러:

```
function crypt(text, text) does not exist   (HTTP 404, code 42883)
```

- **원인**: Supabase는 `pgcrypto`를 `public`이 아니라 **`extensions` 스키마**에 설치한다.
  그런데 함수들이 전부 `security definer set search_path = public` 으로 고정돼 있어
  `crypt()`·`gen_salt()` 를 찾지 못한다.
- **영향 범위**: `register_student`(가입) / `login`(로그인) / `teacher_reset_pin`(PIN 초기화)
  → 즉 **학생이 가입조차 못 하는 상태**였다. 배포 링크만 고쳐도 앱은 못 쓴다.
- **수정(2026-07-21, `supabase/schema.sql`에 반영 완료)**
  - `create extension if not exists pgcrypto;` → `... with schema extensions;`
  - 함수 13개의 `set search_path = public` → `set search_path = public, extensions`
