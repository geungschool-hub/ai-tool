## 이 폴더의 규칙
- **한 소단원 = 한 파일 = 한 퀴즈.** 문항을 더할 때는 **뒤에 이어 붙인다**(앞 문항의 번호가 밀리면 학생 진도가 어긋난다).
- 선택지 **4개**, 정답 표시는 **★**, 해설은 **존댓말**(2026-08-18 교사 결정).
- 각 문항 끝에 `*(무엇을 묻는 문항인가: …)*` 한 줄을 단다 — 나중에 중복 대조와 이원목적분류에 쓴다.
- 정답 번호가 한쪽으로 쏠리지 않게 ①~④를 고르게 배치하고, 파일 끝 「제작 기록」에 분포를 적는다.
- 문항·해설의 진술은 **교과서 본문에 근거가 있는 것만** 쓴다. 읽기자료·교사용 지도서에서 가져올 때는 그렇다고 밝힌다.
- **교과서와 다르게 적기로 한 것은 파일 머리에 이유와 함께 남긴다**(어법·최신 학설 등 교사 판단으로 고친 자리).
  예: 1-4 「A과 T」→「A와 T」 · 1-4 유전자 정의에 RNA 추가 · 1-5 프라이머를 RNA로 한정.
- **위첨자는 문자가 아니라 `<sup>` 태그**로 쓴다(앱이 발문·선택지·해설을 모두 innerHTML 로 그린다).
  단, 라이브 1-2 뒤쪽 문항에 2026-08-20부터 들어가 있는 Iᴬ·Xʳ 같은 **문자**는 그대로 둔다(정상 렌더 확인됨).

## 올리는 법 (md → 라이브)

절차 정본은 **`작업노트/방법_복습퀴즈_추가.md`** 다. 요약하면 —

| 무엇 | 명령 |
|---|---|
| 지금 라이브 상태 보기 | `node "생물의 유전/활동/_퀴즈올리기.js"` |
| 있는 퀴즈 **뒤에** 문항 이어 붙이기 | `node "생물의 유전/활동/_퀴즈올리기.js" --append <퀴즈id> <조립기>` → `--write` |
| 새 소단원 퀴즈 올리기 | `node "생물의 유전/활동/_퀴즈올리기.js" --new <조립기>` → `--write` |

- ★**문항은 뒤에만 붙이고 퀴즈 id 는 바꾸지 않는다.** 학생 진도가 문항 번호로 저장돼 있어 앞을 건드리면 어긋난다.
  도구가 앞부분이 한 글자라도 다르면 **쓰기 전에 멈춘다.**
- 검사는 `_퀴즈검사.js` 한 벌을 모두가 같이 쓴다(존댓말·정답 번호 대조·「기초/심화」 이름 금지·위첨자 태그 등).
- `--write` 는 quizzes·quizMeta 를 `quizBackups/` 에 백업한 뒤 쓰고, 키를 정렬해 깊은 비교로 재검증한다.
- 퀴즈 **id 를 바꾸는 일**(= 학생 기록 이사)은 `_migrate_퀴즈_단원통합.js` 가 본보기다. 되도록 하지 않는다.
- 학교망이 TLS 검사 프록시라 실패하면 앞에 `NODE_TLS_REJECT_UNAUTHORIZED=0` 을 붙일 것.
