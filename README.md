# ai-tool — GitHub Pages 로 서비스되는 교사 도구

`https://geungschool-hub.github.io/ai-tool/…` 주소로 열리는 것만 여기 둔다. 교사 자료·작업 기록은 비공개 레포 `teacher-work` 에 있다.

| 폴더 | 무엇 |
|---|---|
| `attendance-checklist_mobile/` | 출결 체크리스트 (폰 설치 PWA) |
| `class seat change/` | 자리뽑기 — 학급 허브 `seat.html` 이 가리킨다 |
| `수강신청점검/` | 수강신청 점검 (화면만 여기, 데이터는 Firebase) |
| `early-bird/` | 얼리버드 (전자칠판 북마크) |

Pages 설정: `master` 브랜치 루트(legacy). **커밋 = 배포.** `.nojekyll` 은 `_` 로 시작하는 경로가 Jekyll 에 걸러지지 않게 둔 것.
