## 교과서에서 복원한 값 (검사가 스스로 다시 계산해 대조한다)
```
61쪽 그림 Ⅱ-2 (15 염기)
  DNA 주형 가닥     3′-ACCTACAACCGTCAT-5′   (왼쪽이 3′)
  주형이 아닌 가닥   5′-TGGATGTTGGCAGTA-3′
       전사 ↓
  RNA               5′-UGGAUGUUGGCAGUA-3′   (개시코돈 AUG 는 4번째 염기부터)
아래 가닥을 주형으로 삼으면  5′-UACUGCCAACAUCCA-3′ → 개시코돈이 없다
```
- ★**「코딩 가닥·암호 가닥」은 교과서에 없다** → **「주형이 아닌 가닥」**으로만 부른다. 용어를 지어내지 않는다.
- ★**프로모터 부위의 염기도 교과서에 없다** → 글자를 적지 않고 빗금 상자로만 그린다.

## ★심장 셋
1. **주형은 프로모터가 정한다** — ①에서 학생이 고르고, 틀리면 「5′ 이 오른쪽에 생긴다 · AUG 가 없다」를 보여 준다. 💪 p1 이 「프로모터가 반대쪽이면?」으로 오개념(위쪽이 늘 주형)을 되받는다.
2. **풀리는 자리가 옮겨 간다** — ②의 거품은 중합효소를 따라 이동하고 **지나간 자리는 다시 감긴다**. 복제(끝까지 풀린다)와 갈리는 자리다.
3. **RNA 는 주형이 아닌 가닥과 글자가 같다** — ④에서 세 줄을 겹쳐 놓고 T↔U 자리만 보라로 뜬다. 이름 붙이기는 **직접 해 본 뒤에**.

## ② 연출 무대 9국면 (한 국면에 한 사건)
```
0 이중나선          1 중합효소가 프로모터에 결합   2 이중나선이 풀린다
3 첫 라이보뉴클레오타이드   4 나아가며 RNA 가 길어진다   5 되감기고 RNA 가 떨어져 나온다
6 유전자 끝에 이른다  7 RNA 가 방출된다             8 중합효소가 DNA 에서 떨어진다
```
- 국면 번호를 숫자로 박지 않는다 → `TX_PH_BIND/OPEN/FIRST/MOVE/REWIND/END/RELEASE/OFF`.
- 불변식: 거품이 있는 국면에서 `TX_MADE[ph] === TX_POLCOL[ph] − TG.geneFrom + 1`.
- **사다리 모양**으로 그린다(꼬임은 방향성이 헷갈린다 — 1-5 에서 확정). 자막에 「실제 DNA 는 꼬여 있으나 펴서 그렸다」 한 줄.
- 무대에 **염기 글자가 없다** — ③이 그 답이기 때문이다.

## 함정
- `state` 에 **초기값이 `null` 인 칸을 하나도 두지 않았다** — 「없음」은 `0` 또는 `''`. (`typeof null === 'object'`·`Number(null)===0` 두 버그의 뿌리 · 경위는 [[생물의유전_활동_유전부호해독]])
- `resetSec('grid')` 는 **④(`named`·`t4`)까지 함께 지운다** — ④ 는 ③ 이 만든 RNA 위에서만 뜻이 있는 결과다.
- `CELL_W`(28) 는 CSS `.cell` 의 폭 26 + 좌우 여백 1 과 손으로 맞춘 값이다. 어긋나면 격자가 밀린다.
- SVG 문자열 안의 작은따옴표는 `\'` 대신 **`&#39;`** 로 적는다 — 편집 도구를 거치며 역슬래시가 사라져 문법 오류가 났다.
- `.stage-wrap` 에 `overflow:hidden` 을 주지 않는다. `svg.stage{min-width:560px}` + `overflow-x:auto` 로 좁은 화면을 흡수한다.
- 브라우저 실측은 로컬 서버(`python -m http.server 8765`)로 했다. **스크린샷이 이따금 30초 타임아웃**을 낸다 — 다시 부르면 된다. 좁은 화면은 같은 origin **iframe(430·768·1000·1180px)** 으로 쟀다.
