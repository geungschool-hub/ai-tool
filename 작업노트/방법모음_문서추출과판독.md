## 1. HWP(.hwp) 텍스트 추출

교사가 주는 `.hwp`는 보통 **한글 5.0 = OLE 복합문서**다(시그니처 `D0CF11E0A1B11AE1`).

```python
import olefile, zlib, struct   # pip install olefile (기본 미설치)
ole = olefile.OleFileIO('파일.hwp')
fh = ole.openstream('FileHeader').read()
compressed = bool(fh[36] & 1)                       # 36바이트 플래그 bit0
data = ole.openstream(['BodyText', 'Section0']).read()
if compressed:
    data = zlib.decompress(data, -15)               # raw deflate(-15), zlib 헤더 없음
# HWP 레코드: header=uint32, tag=header&0x3ff, size=(header>>20)&0xfff
# size==0xfff면 다음 uint32가 실제 크기. tag 67(PARA_TEXT)이 본문, UTF-16LE.
```

### ★함정 — 콘솔 한글 깨짐
Windows 콘솔은 cp949라 추출한 한글을 그냥 print하면 `����`로 깨진다(**데이터는 정상**).
반드시 **UTF-8 파일로 써서 Read 도구로 확인**할 것.

```python
open('_dump.txt', 'w', encoding='utf-8').write(text)   # Read로 확인 후 삭제
```

빠른 미리보기용 `PrvText` 스트림(UTF-16LE)도 있으나 분량 제한·표 구조만 대략이다.
정확한 전체 내용은 BodyText 파싱이 확실하다.

## 2. HWP → PDF 일괄 변환 (한글 프로그램 COM)

```
pip install pyhwpx
```
`Hwp(new=True, visible=False)` + `open()` / `save_as(dst, format="PDF")`.

- 한글(HWPFrame.HwpObject COM)이 설치돼 있어야 한다.
- pyhwpx가 **보안 승인 팝업(FilePathCheckerModule.dll)을 자동 처리**해서 headless 일괄 변환이 된다.
- 실적: 3학년 창체 세특 때 **17건 전부 성공**. 변환된 PDF는 **텍스트 레이어가 살아 있어** 이후 파싱에 유리하다.

## 3. 스캔 PDF(손글씨) 판독

`get_text()`가 빈 문자열이면 이미지 PDF다. **PyMuPDF로 렌더해서 이미지로 읽는다.**

```bash
python -c "import fitz; d=fitz.open(r'...pdf'); p=d[N-1]; pm=p.get_pixmap(matrix=fitz.Matrix(2,2)); pm.save(r'...png')"
```

- 그 PNG를 Read 도구로 읽으면 손글씨가 선명하게 판독된다. **2배율로 충분**, 흐리면 3~4배율 + 부분 확대.
- **회전 처리는 자료마다 다르다 — 여기서 자주 틀렸다.**
  - `rot=270`이 메타데이터에 박힌 PDF는 **PyMuPDF가 렌더 시 자동 보정**하므로 따로 돌리지 않는다.
  - 반대로 3학년 창체 워크시트 세트는 **PIL `ROTATE_90`이 정방향**이었다(ROTATE_270이 아니다).
  → 한 장 먼저 렌더해 눈으로 확인한 뒤 전체를 돌릴 것.
- 페이지당 1명이면 **학번·이름이 우상단**에 있어 자동 매칭이 된다(판독 불확실 표시를 함께 남길 것).
- **대지(contact sheet)**: 여러 쪽의 헤더만 잘라 세로로 이어 붙이면 **한 장으로 반 전체 학번·이름 매핑**을 확인할 수 있다(PIL, 검증됨).

### ★판독의 진짜 위험 — 판독자가 이름을 지어낸다
진화 논설문 판독에서 **실재하지 않는 종명(`흑축나방`)을 판독자가 만들어 낸 사고**가 있었다.
흘림체를 그럴듯한 단어로 "복원"해 버리는 것이라 혼자서는 못 잡는다.
→ **이중 독립 판독**으로 대조할 것. 이름 오독은 **학번으로 명단 매칭**하면 복구되고, 학번도 없으면 이름 별칭 사전으로 폴백한다.

## HTML 인쇄물 → PDF·워드(.docx) 변환 (2026-08-21 확립)
인쇄용 HTML(A4 가로 `.page` 구조)을 만들어 두면 **PDF·워드를 그 하나에서 뽑는다.** 정본은 HTML 하나만 둔다.

### ① PDF — 헤드리스 크롬 (레이아웃이 화면과 100% 같다)
```bash
"/c/Program Files/Google/Chrome/Application/chrome.exe" --headless=new --disable-gpu   --user-data-dir="<임시폴더>"   --no-pdf-header-footer --run-all-compositor-stages-before-draw --virtual-time-budget=6000   --print-to-pdf="<출력.pdf>" "file:///<한글경로는 percent-encoding>"
```
🔴 **`--user-data-dir`(임시 프로필)를 반드시 줄 것.** 2026-08-21에 이걸 빼먹고 돌렸더니
**사용자가 쓰던 크롬에 창이 떠서 놀라게 했다.** 기본 프로필을 공유하면 헤드리스로 뜨지 않고
이미 실행 중인 크롬에 붙어 창·세션 복원이 일어날 수 있다.
- `@page{size:A4 landscape}` 를 그대로 따른다. 머리글·바닥글 없음.
- ★`file://` URL은 **퍼센트 인코딩**해야 한다: `urllib.request.pathname2url` 로 만들 것.
- `@media print`로 감춘 것(화면 전용 안내·클릭 표시)은 **PDF에도 안 나온다** — 의도대로다.
- 확인은 Read 도구로 PDF를 페이지 렌더해서 눈으로 볼 것.

### ② 워드 — `_html2docx.py` (표가 진짜 표로 살아 있어 복붙된다)
위치: `국가수준 학업성취도 컴퓨터 평가/_html2docx.py` · `python _html2docx.py <입력.html> <출력.docx>`
- **lxml + python-docx.** pandoc·Word COM 없이 동작한다(둘 다 이 PC엔 있지만 안 쓴다).
- 하는 일: `.page` 별로 순회 → h1/h2/p/table/div.box 를 문단·표로 옮긴다.
  - **rowspan·colspan을 격자로 풀어 `merge()`** 로 복원한다(안 하면 표가 어긋난다).
  - 셀 안의 블록 스팬(`act·orig·evn·subj·time·sup·ev·cj`)과 `<small>`·`<br>`에서 **줄을 나눈다.**
    ★이걸 빼먹으면 `1교시정상 수업`처럼 붙어 나온다(실제로 한 번 겪음).
  - `.badge` 는 `[담임]` `[감독]` 처럼 **대괄호로** 바꾼다.
  - 배경색은 헤더/exam/pick/period/lunch/moved 만 옮긴다.
  - `.rot-hint`·`.picker`(화면 전용)는 **통째로 버린다.**
- 열 너비는 mm로 직접 준다(가용 폭 = 297 − 좌우 여백 20 = **277mm**). 합이 277이 되게 맞출 것.
- 검증: python-docx로 되읽어 **표 개수·행열·첫 열 텍스트**를 찍어 본다.
