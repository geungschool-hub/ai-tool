# 업무판 (task_management) — 교사 업무 관리 도구

노션에서 옮겨 온 **내 업무 목록**. 폰과 PC에서 같은 것을 본다.

- **라이브** https://geung-taskboard.web.app (`.firebaseapp.com` 도 같은 곳)
- **소스** `task_management/web/index.html` — 단일 파일, 외부 의존 0
- ★**정본은 `task_management/PRD.md`** 다. 데이터 모양·화면 규격·마일스톤·진행 기록(§10)이 전부 거기 있다.
  이 노트는 **갈래 시작점**일 뿐이니, 손대기 전에 PRD §10 의 맨 아래 절을 먼저 읽을 것.
- **다음 할 일은 `_재개지점.md`** 에만 있다.

**바탕화면 바로가기** `업무판.lnk` — 크롬 `--app=` 모드(주소창 없는 창).
아이콘은 `%LOCALAPPDATA%\geung-taskboard\업무판.ico` 에 둔다(USB 를 빼도 안 깨지게).
폰은 크롬에서 **「홈 화면에 추가」**, PC 는 주소창의 **「설치」** — manifest 를 붙여서 아이콘이 제 모양으로 붙는다.

검사 `node task_management/_test_taskboard.js`(828단언) · `_test_cli.js`(111단언) ·
규칙 실측 `node task_management/_rules_probe.js`(라이브를 두드린다 · `--write` 면 허락된 쓰기까지).

## ★세션을 열면 — 판을 한 번 본다

```
node task_management/_cli.js pull
```
- **말하는 조건 셋** — ① 마감이 지난 것이 있다 ② 폰에서 「검토 요청」이 켜져 있다
  ③ 지금 하려는 교과 일이 판과 어긋난다. **셋 다 아니면 아무 말도 하지 않는다.**
- 말할 때도 **3줄 이하**. 항목 내용을 작업노트·커밋 메시지에 옮겨 적지 않는다(레포가 PUBLIC 이다).
- 봇이 할 수 있는 일은 **서버 규칙이** 정한다. 제목 고치기·교사 체크의 글자 바꾸기·검토 요청 켜기는 막혀 있다
  (`node task_management/_rules_probe.js` 로 언제든 두드려 볼 수 있다 · 규칙을 고치면 반드시 다시 돌릴 것).
- `done <id>` 는 **교사가 「완료」라고 말한 뒤에만.** 스스로 판단해 닫지 않는다.
- `add` 로 넣은 것은 `ok:false` 라 **아직 앱 화면에 안 뜬다** — 받아들이는 화면은 M4 에서 붙는다.

## 손대기 전에 알아야 할 것

- **계정 둘** — T(교사)·B(봇). 비밀번호는 교사만 안다. 규칙은 `database.rules.json`(레포에 있다).
- **배포는 호스팅과 규칙이 따로다.** 윈도 node 24 는 `.cmd` 를 못 부르니 `firebase.js` 를 node 로 부른다.
  `node "$APPDATA/npm/node_modules/firebase-tools/lib/bin/firebase.js" deploy --only hosting --project geung-taskboard`
  (규칙은 `--only database`.)
- **검증된 블록 넷**(`PARSE`·`GROUP`·`STORE`·`SYNC`)은 화면을 갈아엎을 때도 건드리지 않는다.
  `localStorage` 는 **STORE 블록 안에서만** 쓴다(테마 `tmTheme`·되돌리기 `tmUndo` 도 거기 있다).
- **문법은 화면에서 칩을 없앤 뒤에도 그대로 산다** — `@담주화` `#교` `!` `+체크` `>id 수정` 을 손으로 치면 먹는다.
- **마감일 판의 빠른 날짜는 파서의 `resolveDate` 를 그대로 부른다** — 화면과 문법이 두 벌로 갈라지지 않게.
- **아이콘은 `_mkicon.js` 가 Node 의 zlib 만으로 찍는다**(의존성 0 유지). 모양을 바꾸려면
  `node task_management/_mkicon.js web` 로 다시 찍어 덮고 hosting 을 배포한다. 크기를 바꾸면 manifest 도 함께.
- **봇 비밀은 USB 에 없다** — `%USERPROFILE%\.config\taskboard\bot.json` 한 곳뿐이다.
  **다른 PC 에서는 `node _cli.js setup` 을 한 번 돌려야** 봇 명령이 돈다(그 전엔 `pull --from=<스냅샷>` 만 된다).
- **CLI 는 URL·토큰·비밀번호를 오류에도 찍지 않는다** — RTDB 주소에는 `?auth=` 가 붙어 있다.

## ★두 번 밟은 함정 (PRD §10 에 자세히)

| | |
|---|---|
| 규칙을 실제로 두드려 보지 않은 것 | `log/$id` 가 덧붙이기 전용이라 **되돌리기·삭제가 라이브에서 통째로 반려**되고 있었다. 다중 경로 쓰기는 원자적이다 — 한 경로가 막히면 전부 막힌다 |
| 앵커 없는 `closest('[data-...]')` | `<html data-theme="dark">` 까지 올라가 **설정 ✕ 가 안 먹었다.** `closest('button[data-theme]')` 처럼 앵커를 준다 |
| CSS 특정도 | `.row .meta [data-edit]` 가 `.row .m-area` 를 이겨 PC 화면에 태그가 겹쳤다. 숨김 규칙에도 같은 깊이를 준다 |
| 범위로 지우기 | 캘린더 CSS 를 「A 부터 B 까지」로 지웠더니 사이의 `nav` 규칙이 함께 날아갔다. **지우기 전에 그 구간을 눈으로 볼 것** |

> 검사가 통과해도 라이브에서 안 되는 것이 있다 — **규칙·특정도·배선은 브라우저에서 직접 눌러 봐야 잡힌다.**
> 확장이 안 붙으면 [[chrome-extension-account]] 대로 크롬 계정부터 본다. 창 폭이 안 줄면 **390px iframe** 으로 잰다.
