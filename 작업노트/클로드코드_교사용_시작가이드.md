# 클로드 코드 시작 가이드 (동료 교사 추천용)

2026-07-26 제작. 동료 교사에게 "클로드 코드로 작업하는 걸 추천"하려고 만든 설치·시작 가이드.

## ★ 공개 주소

```
https://geungschool-hub.github.io/claude-guide/
```

레포 `geungschool-hub/claude-guide` (PUBLIC) · Pages built · 2026-07-26 배포 확인(HTTP 200, UTF-8).

> 처음엔 클로드 아티팩트(claude.ai 호스팅)로 만들었으나, **학교 계정에 흔적을 남기지 않으려고 GitHub Pages로 옮기고 아티팩트는 폐기**했다. 같은 판단이 필요하면 처음부터 Pages로 갈 것.

## 산출물

| 파일 | 역할 |
|------|------|
| `AI tool/클로드코드_시작가이드_교사용.html` | **정본.** 완전한 단일 HTML(doctype·charset 포함, 오프라인 동작) |
| `긍스쿨 허브/claude-guide/index.html` | 배포 복사본. 정본을 그대로 복사한 것 |
| `AI tool/클로드코드_시작가이드_교사용.md` | 초안(텍스트판). 톤이 옛 버전 — 웹만 쓸 거면 불필요 |

## ★ 수정할 때 (2벌 관리 주의)

정본을 고친 뒤 **배포 폴더로 복사해야 반영된다.** 안 하면 웹은 옛날 내용 그대로.

```powershell
Copy-Item "E:\AI tool\클로드코드_시작가이드_교사용.html" `
  -Destination "E:\AI tool\긍스쿨 허브\claude-guide\index.html" -Force
cd "E:\AI tool\긍스쿨 허브\claude-guide"; git add -A; git commit -m "내용 수정"; git push
```

- 반영까지 1~2분. `긍스쿨 허브/`는 부모 ai-tool에서 gitignore(중첩 레포)라 별도 커밋이 필요하다.
- 절차 정본은 `배점계산기앱_허브등록.md`의 **(B) 별도 public 레포 + Pages** 항목.

## 설계 결정 (다시 만들 때 되풀이하지 말 것)

- **디자인은 학습지 양식 B를 그대로 계승.** CLAUDE.md의 토큰(파랑 `#0F4E96`·초록 `#25702F`, 좌측 보더+파스텔 섹션 제목, 회색 바탕 위 흰 종이). 동료가 받았을 때 "이 사람이 만든 자료"로 읽히게 하려는 의도.
- **경고 박스를 2개로 제한.** 초안에서 빨간 경고가 8개였는데 "이래서야 하고 싶겠냐"는 피드백을 받음. → "절대 금지 3가지"를 **"이 세 가지만 지키면 됩니다"(초록)** 로 뒤집고, 나머지 경고는 해결 프롬프트로 대체. 겁주는 대신 복사해 붙일 것을 주는 방식.
- **글씨 크게.** 본문 18px / 섹션 제목 23px / 표 16px. 초안(16.5px)은 가시성 부족 판정.
- **Supabase를 추천, Firebase는 대안.** 데이터가 표로 보여 학생 제출물 확인·CSV 추출이 쉽다는 이유. (내 기존 앱들은 Firebase지만 새로 시작하는 사람 기준)
- **팀 계정·초대 메일 안내는 뺐다.** 각자 Pro 구독하는 구조로 통일.
- **첫 실습은 랜덤 뽑기·모둠 편성 페이지 7단계.** 개인정보가 안 들어가고 전자칠판에서 바로 쓰여서 성공 체감이 크다.
