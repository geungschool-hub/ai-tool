코딩을 배우는 게 아닙니다. 컴퓨터에게 한국어로 시키는 것이 전부입니다. 이 문서 하나로 설치부터 실제로 쓸 만한 첫 결과물까지 끝냅니다.

00 이게 대체 뭔가요

챗지피티나 클로드 웹사이트는 대화만 합니다. 답을 받아서 내가 복사해 붙여넣어야 하죠.

클로드 코드는 내 컴퓨터의 폴더를 직접 열어보고, 파일을 만들고 고칩니다. 핵심은 “결과물 파일이 내 폴더에 실제로 생긴다”는 것입니다.

이렇게 시키면이런 게 생깁니다
“이 교과서 PDF에서 그림 뽑아서 학습지 만들어줘”인쇄용 학습지 + 정답지
“수행평가 채점표를 학생별로 정리해줘”엑셀 · 표 파일
“학생들이 폰으로 제출하는 페이지 만들어줘”실제 작동하는 웹앱
“이 hwp 파일들 내용 전부 뽑아서 합쳐줘”정리된 텍스트 파일
“학급 임원 선거 투표 앱 만들어줘”학생 폰 기표 + 전자칠판 개표 화면
먼저 마음 놓으셔도 됩니다 명령어를 외울 필요 없습니다. 영어로 쓸 필요 없습니다. 방향이 이상하면 Esc 한 번으로 멈춥니다. 망가뜨릴 걱정 없이 이것저것 시켜보세요.

04 첫 실습 — 15분 만에 쓸 만한 것 하나 만들기

만들 것: 수업 시간에 쓰는 랜덤 뽑기 · 모둠 편성 페이지. 결과가 눈에 바로 보이고, 다음 시간부터 실제로 쓰입니다.

방법 아래 프롬프트를 순서대로 하나씩 붙여넣으세요. 한 번에 다 시키지 말고, 결과를 열어 확인한 뒤 다음으로 넘어가는 게 요령입니다.
step 1 · 설계부터 수업 시간에 쓸 랜덤 뽑기 페이지를 만들 거야. 바로 만들지 말고, 어떤 기능이 필요할지 먼저 정리해서 보여줘. 나는 고등학교 교사고 전자칠판에 띄워서 쓸 거야.
step 2 · 기본 화면 좋아. 그 계획대로 HTML 파일 하나로 만들어줘. 외부 파일 없이 그 파일만 더블클릭하면 열리게. 번호 1번부터 30번까지 중에 한 명을 뽑는 기능부터.
step 3 · 명단 넣기 번호 대신 내가 이름 명단을 직접 붙여넣을 수 있게 해줘. 한 줄에 한 명씩. 다음에 열어도 명단이 그대로 남아 있어야 해.
step 4 · 보는 재미 뽑을 때 이름이 드르륵 돌아가다가 멈추는 연출을 넣어줘. 전자칠판에서도 잘 보이게 글씨를 아주 크게.
step 5 · 실제로 필요한 것 이미 뽑힌 사람은 다시 안 나오게 하는 기능이랑, 오늘 누가 뽑혔는지 목록을 아래에 보여줘. 전체 초기화 버튼도.
step 6 · 확장 모둠 편성 모드도 추가해줘. 몇 명씩 몇 모둠으로 나눌지 정하면 자동으로 섞어서 배정해주는 기능.
step 7 · 마무리 마지막으로 다듬어줘. 실수로 초기화 눌렀을 때 되돌리기, 결과를 복사할 수 있는 버튼, 그리고 태블릿 터치로도 잘 눌리게 버튼 크기 키우기.
여기까지 오셨다면 감을 잡으신 겁니다 요령은 딱 하나 — 한 번에 하나씩, 확인하고 다음으로. 이제 진짜 하고 싶었던 걸 같은 방식으로 시키시면 됩니다.

05 그다음 시켜보기 좋은 일

무난하게 성공하는 것부터 시작해 감을 잡으시길 권합니다.

교과서 PDF → 학습지 이 PDF에서 그림 뽑아서, 그림에 번호 붙인 학습지 만들어줘. 인쇄하면 A4에 딱 맞게.
수행평가 세트 혈액형 판정 실험 수행평가 활동지랑 20점 배점 루브릭 만들어줘.

잡무 자동화 이 폴더 hwp 파일 전부 열어서 학생 이름이랑 활동 내용만 뽑아 표로 정리해줘.
있는 자료 고치기 지난번 학습지에서 ‘티록신’을 ‘타이록신’으로 다 바꿔줘. 2022 개정 용어야.

💻 VS Code — 만든 파일을 눈으로 보기 무료 · 로그인 없음

클로드 코드는 터미널에서 결과를 글로 알려줄 뿐, 파일 자체를 보여주진 않습니다. VS Code를 같이 켜 두면 만들어지는 파일이 눈앞에서 바뀌는 게 보여서 훨씬 안심이 됩니다.

이럴 때 편합니다

  • 클로드가 만든 파일을 열어 내용 확인 — 학습지 문구, 표 내용이 제대로 들어갔는지
  • 글자 하나, 숫자 하나 정도는 직접 고치기 (매번 시키는 것보다 빠릅니다)
  • 왼쪽에 폴더 구조가 한눈에 — 뭐가 어디 있는지 파악됩니다

설치: code.visualstudio.com 에서 받아 설치. 계정도, 설정도 필요 없습니다.

터미널 창을 아예 안 띄우는 방법

VS Code 확장 마켓플레이스(왼쪽 네모 아이콘)에서 Claude Code를 검색해 설치하면, VS Code 안에서 바로 클로드에게 시킬 수 있습니다. 파일이 바뀌는 모습과 대화창이 한 화면에 있어서 처음 배울 때 특히 편합니다.

화면이 영어라 부담스러우면 같은 확장 마켓플레이스에서 Korean Language Pack을 설치하면 메뉴가 한국어로 바뀝니다.

🐙 Git + GitHub 가입 필요

둘은 다른 것입니다.

  • Git = 내 컴퓨터에 깔리는 프로그램. “자동 저장 + 되돌리기” 기능.
  • GitHub = 웹사이트. Git으로 관리한 폴더를 인터넷에 보관하는 곳. 계정 필요.

뭘 할 때: 파일을 잘못 고쳤을 때 되돌리기 / 학교 PC ↔ 집 PC 자료 동기화 / 만든 웹앱을 학생이 접속할 주소로 올리기

⌨️ GitHub CLI — 깃허브 일까지 클로드에게 맡기기 무료

CLI는 프로그램 이름이 아니라 방식을 가리키는 말입니다. 마우스로 클릭하는 대신 명령어를 쳐서 쓰는 프로그램이라는 뜻이에요. 클로드 코드 자체도 CLI입니다.

GitHub CLI는 깃허브 웹사이트에서 클릭으로 하던 일 — 저장소 만들기, 공개 설정, 배포 켜기 — 을 명령어로 하는 도구입니다.

이걸 깔면 뭐가 달라지나

없을 때

깃허브 사이트에 들어가 저장소를 만들고, 파일을 올리고, 설정에서 배포를 켜는 걸 선생님이 직접 하셔야 합니다.

있을 때

한 줄만 시키면 클로드가 저장소 생성부터 주소 발급까지 알아서 합니다.

이 앱 깃허브에 올리고 학생들이 접속할 주소까지 만들어줘.

설치

Windows PowerShell 
winget install --id GitHub.cli

맥은 brew install gh, 또는 cli.github.com 에서 직접 받아도 됩니다.

로그인 — 이건 직접 하셔야 합니다

설치 후 터미널에 아래를 치면 브라우저가 열리며 깃허브 로그인을 묻습니다. 한 번만 하면 됩니다.

gh auth login

물어보는 것들은 기본값(GitHub.com → HTTPS → 브라우저로 로그인)으로 넘기시면 됩니다.

로그인 확인 
gh auth status
여기까지 하면 이후로는 배포가 필요할 때마다 말로만 시키면 됩니다. 깃허브 사이트에 들어갈 일이 거의 없어집니다.

만든 웹페이지(설문·퀴즈·투표 앱 등)를 무료로 인터넷에 올려 학생들이 폰으로 접속하게 하는 기능입니다. GitHub 계정만 있으면 됩니다.

이 앱을 GitHub Pages로 배포해서 학생들이 접속할 주소 만들어줘.

여기 올린 페이지는 주소를 아는 사람이면 열 수 있습니다. 학생 이름이 화면에 뜨는 앱이라면 비밀번호나 로그인 장치를 함께 넣으시면 됩니다. 그것도 말로 시키면 만들어 줍니다.

이 앱, 학생 이름이 아무나에게 보이지 않게 로그인 장치를 넣어줘.
🗄️ Supabase — 제출한 걸 모아야 할 때 둘 중 하나만

만든 페이지가 여러 학생의 입력을 받아 저장해야 한다면 데이터 보관소가 필요합니다. 선택지는 크게 둘인데, 새로 시작하신다면 Supabase를 권합니다.

깃허브·이메일로 로그인. 데이터가 엑셀처럼 표로 보입니다. 화면에서 직접 값을 고치거나 CSV로 내려받기 쉬워서, 학생 제출물을 확인·정리하기 편합니다.
supabase.com

Firebase

구글 계정으로 로그인. 실시간 반영이 편해 투표 현황판처럼 즉시 갱신되는 화면에 강합니다. 대신 데이터가 표가 아닌 계층 구조라 훑어보기가 덜 직관적입니다.
firebase.google.com

둘 다 무료 구간으로 한 학급~한 학년 규모는 충분합니다. 둘 중 하나만 고르세요 — 둘 다 쓰면 관리가 두 배가 됩니다.

설정은 클로드가 화면을 단계별로 안내해 줍니다. 다만 웹사이트에서 프로젝트 만들고 키 복사하는 건 선생님이 직접 해야 합니다. 만들고 나서 이 한 줄만 시켜 두시면 접근 권한이 정리됩니다.

이 데이터베이스 접근 규칙 확인하고, 아무나 읽을 수 없게 안전하게 설정해줘.
📄 한글(HWP) 파일 기존 보유

학교 자료는 대부분 hwp죠. 두 가지 경우가 있습니다.

  • 텍스트만 뽑으면 될 때 → 아무것도 안 깔아도 됩니다. 클로드가 파이썬으로 직접 읽어냅니다.
  • PDF로 변환하거나 서식까지 살려야 할 때 → PC에 한글 프로그램이 설치돼 있어야 합니다. 클로드가 한글을 자동 조종해서 변환합니다.
🔑 클로드 API 키 — 내 앱에 AI를 넣을 때 별도 과금

구독료와는 별개로 돈이 나갑니다. 가장 헷갈리는 부분이라 짚어 둡니다.

  • 클로드 코드를 쓰는 것 = Pro 구독으로 커버 (추가 요금 없음)
  • 내가 만든 앱이 스스로 AI를 호출하는 것 = 별도 API 키 필요, 쓴 만큼 과금

예: “학생 활동 기록을 넣으면 생기부 초안을 뽑아주는 프로그램”을 만들어 쓰는 경우.

발급 → console.anthropic.com 에서 결제수단 등록 후 API 키 생성

API 키는 비밀번호와 같습니다 키가 든 파일은 인터넷에 올라가지 않게만 관리하면 됩니다. 올리기 전에 아래 한 줄을 시키면 알아서 걸러 줍니다.

08 학생 정보 다루기

복잡하지 않습니다. 아래 세 가지만 습관으로 만들면 됩니다.

1
인터넷에 올릴 폴더와 명단 폴더를 나눠 둔다
학생 실명·학번이 든 파일은 따로 보관하고, 공유하는 자료에는 “A반 3번”처럼 번호로 적습니다. 한 번 정해두면 그다음부터는 신경 쓸 일이 없습니다.
2
올리기 전에 한 줄로 점검을 시킨다
지금 올리려는 파일 중에 학생 실명·학번·연락처·성적, 또는 API 키가 든 게 있는지 검사해줘.

GitHub에 올리기 전, 앱을 배포하기 전에 이것만 시키면 됩니다.

3
저장소는 PRIVATE으로 시작한다
GitHub 저장소를 만들 때 PRIVATE(나만 보기)을 고르세요. 학생이 접속할 페이지가 필요하면 그 부분만 따로 공개하면 됩니다.
한 가지만 기억하신다면 인터넷에 한 번 올라간 파일은 지워도 기록에 남습니다. 그래서 “올리기 전에 점검” 한 단계가 사후 수습보다 훨씬 쉽습니다. 위 2번 프롬프트 하나면 끝나는 일이에요.
