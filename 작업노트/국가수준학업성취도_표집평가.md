# 국가수준 학업성취도 평가 (2026 · 컴퓨터 기반 표집평가) — 업무 숙지 노트

작성 2026-08-11. 원문 3개는 `국가수준 학업성취도 컴퓨터 평가/` 폴더(붙임1 시행매뉴얼 hwpx+**PDF**(같은 내용·원본 42쪽) · 붙임2 교사용 포털 매뉴얼 PDF 34p · 붙임3 학생 응시방법 PDF 10p).
★붙임1은 hwpx 텍스트 추출 시 표 안 일부가 비어 나온다 — **PDF판(스프레드 25쪽)을 페이지 렌더로 전수 판독해 대조 완료**(2026-08-11, 불일치 0건·누락분 아래에 반영).
사용자는 **고2 담임 + 부서 업무가 학력평가** → 이 학교(고교) 기준으로 정리. 시행일 기준 **고등학교 2학년**이 평가 대상 학년이다.

## 0. 한 줄 개요
- 2022년부터 **컴퓨터 기반(CBT) 표집평가**. 학교당 **2개 표집학급**, 학생별로 가~라형 4유형 중 미리 배정된 서로 다른 검사지.
- 고2: **국어·수학·영어 + 설문**, 교과별 **50분**, 시행일 **9.4.(금)**. (중3은 8.27.(목), 45분, 4교시 사회/과학 추가)
- 근거: 초·중등교육법 제9조(특별한 사유 없으면 응시 의무 — 특별한 사유=천재지변·법정 전염병 등). 출제·채점·결과통지는 KICE 위탁(행정권한 위임·위탁 규정 §45③4).
- 연혁: '86~'92·'98~'07 표집 → '93~'97·'08~'12 전수 → '13~'16 전수(중3·고2 국수영, '13년 초등 폐지) → '17~'21 표집 → **'22~ 컴퓨터 기반 표집**.
- 표집: 2단계 층화 군집 표집, 전체 대상의 약 3%(중 사회·과학은 1.5%). 제외 학생 = **특수교육대상학생(평가 교과 미이수)·외국국적만 소지한 학생**.
- 검사지 구성: 유형별 모든 학생 동일한 **공통문항군** + 학생마다 다른 **비공통문항군**.
- 포털: **inaea.re.kr** (학업성취도평가지원포털) · 기술지원센터 **1600-4312** (평일 08~17시, 시행일은 07~18시 점심 포함) · KICE 평가 시행 상황실은 시행일(8.27.·9.4.) 운영.

## 3. 시행 전 핵심 절차 (포털)
1. 학교관리자: [마이페이지]-[학교관리]에서 **나이스 반 매칭**(타 시험으로 기매칭이면 생략 가능).
2. 담임: [마이페이지]-[시험관리]-시험준비하기 → 표집학급 선택 → **학생정보 불러오기** → 응시자 확인·특이사항(특수교육/다문화 등) 선택 → **스크롤 끝까지 내려야 '확인 후 배포' 활성화** → 배포.
   ★자율평가·진단검사를 이미 했어도 **반드시 다시 실행**해야 한다.
   ★표집평가는 학급·교과가 사전 설정돼 '설정완료' 상태로 뜬다(표집 대상 아닌 교과는 '미설정'·배포 불가).
3. 출력물 4종(학교관리자 or 담임): **응시표**(계정+비밀번호 → 보안·봉인), **응시자 명부**, **연습지**, **시험배포현황**. 응시표는 일괄형(1쪽 6명)/개별형 선택.
   ★사전·모의테스트용 응시표는 **본시행에 사용 불가** — 본시행용을 새로 출력.
4. 학생 연습: 포털 [체험하기]-[문항 체험하기](상시) — 특히 **수학 수식 입력** 연습. 모의테스트는 ~9.3.까지.

## 4. 시행 당일 (감독 흐름)
- 30분 전(담임): 시험실 PC 전원·상태 확인, 전학생 PC에 **전용 브라우저 MyCBT** 실행(안 되면 일반 브라우저로 inaea.re.kr → [학업성취도평가 응시하기]).
- 20분 전(담임): 학생별 PC 배치 계획 확인, **응시 현황 칠판 기재**, 유의사항·시간표 시험실 전면 부착(필요시). 10분 전: 소지금지물품 수거·출결 확인. 감독교사는 20분 전 입실해 응시자 명부·응시표 인수.
- 시행관리자는 시험 1시간 전 응시표 봉투 개봉·확인 후 1교시 감독에게 배부. 이상 시 즉시 1600-4312.
- 감독: [시험관리]-[시험보기] 탭 → 과목 [시험감독] → **[감독교사 프로그램](KICE CBT Hub) 우선**, 불가 시 [온라인 시험 진행]. 감독 프로그램은 시험자료를 미리 준비하고 백그라운드 동작(동시에 여러 시험 불가 — 종료 후 다음 과목).
  ★**감독 프로그램 화면을 먼저 열어야 학생이 로그인할 수 있고, 감독이 [시험시작]을 눌러야 학생 [응시] 버튼이 활성화된다.**
- 감독 화면 기능: 시험시작/종료/재시작/**시험시간 일괄연장**, 학생별로 시험지보기·**시간 연장**·**동영상 재생횟수 초기화**(1회 제한 문항 재청취 허용)·**최종제출 처리**(강제종료)·**최종제출 취소**(재응시 복구)·응시기록 초기화·1:1 채팅.
- 학생 상태: 미응시 → 응시대기(로그인) → 응시중 → 응시완료(최종제출). 화면 이상은 F5.
- PC 장애: 새로고침 → 재부팅(응시시간 자동 일시정지) → 자리 이동/여분 PC → 원격지원(1600-4312). 지연 시간만큼 감독이 추가 시간 부여. 당일 업체 지원 인력 1명 학교 배치.
- 연습지: 매 교시 배부 → 종료 후 **전량 회수·매수 확인·파쇄**. 응시표도 평가 후 수거·파쇄.
- 매 교시 종료: 모든 학생 제출 확인 → [종료] → 응시현황 이상 유무 최종 확인 → 연습지 회수·파쇄. 휴식 10분 후 다음 과목.
- 4교시 설문: [설문시작]만 누르면 됨(별도 제어·종료 불필요, 익일 자동 종료). 전 문항 응답해야 제출 가능. 설문 내용 = 교과별 자신감·흥미·가치·학습의욕, 학교생활, 사회·정서적 역량 등 → **개인별 분석이 결과표에 담김**(성실 응답 지도).

## 5. 시행 후
- 보안서약서(붙임2-3 양식): 책임자·시행관리자·**모든 감독교사**·시스템관리자 서명 → 스캔 → [시험관리]-[협의회비]-[보안서약서등록] (시행계획별 1파일).
- [협의회비]-'시험관리자 설문'에 교시별 특이사항 작성(시험관리자 = 협의회비 지급 대상 최대 3명, 학교 자율 선정). 수당 대상자는 개인정보·계좌 동의서 개별 등록.
- 학교장 설문(학교관리자 계정)·교과 담당 교사 설문(교사 본인 계정, 학급당 교과별 1명) ~9.9.
- 결과: 교과별 성취수준 4단계(4=거의 모두 이해 ~ 1=많은 노력 필요) + 영역별 상세 + 정의적 영역 설문 결과. **학생용 결과표만 제공** · 출력 11.25.~12.15.(연장 불가).
- 가정통신문에 넣을 것: **보호자도 포털에서 자녀 결과 직접 확인 가능**(방법·일정은 11월 중 포털 공지) — 원문 34p 예시문에 포함된 문구.

## 6. 함정·유의 (걸리기 쉬운 것)
- **학생정보 불러오기는 시행 1일 전까지 필수**, 다른 시험을 이미 했어도 생략 불가. 사전테스트 하려면 그 전날까지.
- 응시용 비밀번호는 **전 과목 동일** · 반/번호는 **2자리 입력**(5반 → '05').
- 영어 듣기 문항은 **1회 재생 + 재생 중 문항 이동 불가**. 수학 외 전 교과에 음성 문항 → **이어폰 필수**·음량 사전 조절. 소리 안 나는 PC로는 응시 불가.
- **[최종제출] 후 재응시 불가**(감독의 '최종제출 취소'로만 복구). 시간 종료 시 자동 최종제출.
- 학생이 시험 중 타 사이트 접속 = **부정행위** + 회선 저하로 타 학생 피해. 부정행위 적발 교시는 미응시 처리(다음 교시는 정상 응시).
- 특정 교시 지각·미응시: 시스템 조치 불필요, 가능한 교시부터 응시시키면 됨.
- 표집학급 **당일 교체 불가**(부득이하면 기술지원센터). 반 분리 시행은 가능(사전 PC 점검 전제).
- 평가도구는 보안자료 — 출력·촬영·녹화 일체 금지(교사 포함).
- 시행 당일 표집학급 외 학급은 대체 학사 운영 가능(자율학습·창체 등 — 대체 시험지는 중학교만).
- 특수교육대상학생용 별도 평가 시스템 없음 → 별도 교실에서 교육 프로그램 제공.
- 학생 PC 해상도 1280×768 이상 필요. 전용 브라우저 설치파일은 포털 [소통하기]-[공지사항].
- 모의테스트 시스템은 ~9.3.(목) 운영이나 **8.27.(목)은 중학교 시행일이라 미운영**. 체험하기는 상시.
- 시행 준비 문의는 기술지원센터(1600-4312) 외에 포털 [문의하기]로도 가능.
- 지진 발생 시(붙임2-5): 학교 책임자/감독이 '시험 일시 중지·책상 아래 대피' 지시 → 책임자가 교실 밖 대피 or 시험 재개 결정(안정시간 10분 내외) → 감독은 **시험 중지 시각 필수 기록**, 순연 반영한 '중지시각~재개시각~종료시각' 칠판 판서 → 책임자는 기술지원센터에 보고. 재개 지시 불응·외부 이탈 학생은 불가피하게 시험 포기 처리.
