## 0. 세 무대에 공통으로 적용하는 뼈대

### 0-1. 「결과 먼저, 애니메이션은 장식」 원칙 (헤드리스 통과의 핵심)

무대의 최종 모습은 **루트 `<svg>`에 붙는 클래스 문자열 하나**로 완전히 결정된다.
애니메이션은 그 클래스를 잠시 되감았다가 다시 감는 행위일 뿐이다.

```js
/* 무대 상태는 순수 데이터 → 클래스 문자열 */
function stageClass(st){            // st = {exp:'g', cond:'ra', dead:true, seeS:true, seeR:true}
  return 'stage exp-' + st.exp + ' cond-' + st.cond +
         (st.dead ? ' is-dead' : ' is-alive') +
         (st.seeS ? ' see-s' : '') + (st.seeR ? ' see-r' : '') + ' step-final';
}

var CAN_ANIM = (typeof setTimeout !== 'undefined') &&
               (typeof clearTimeout !== 'undefined') &&
               (typeof document !== 'undefined') && !prefersReduced();

function prefersReduced(){
  if (typeof matchMedia === 'undefined') return false;
  try { return matchMedia('(prefers-reduced-motion: reduce)').matches; } catch(e){ return false; }
}

function render(st){                       // ★언제나 동기적으로 최종 상태를 확정한다
  document.getElementById('g_stage').setAttribute('class', stageClass(st));
  renderCaption(st);                       // 캡션 <li> 전부 채움
  renderTable(st);                         // 관찰 기록표 셀 전부 채움
}

var timers = [];
function clearTimers(){
  if (typeof clearTimeout === 'undefined') { timers = []; return; }
  for (var i=0;i<timers.length;i++) clearTimeout(timers[i]);
  timers = [];
}

function play(st){
  render(st);                              // ① 결과 확정 — 헤드리스·reduced-motion은 여기서 끝
  if (!CAN_ANIM) return;
  clearTimers();
  var el = document.getElementById('g_stage');
  el.setAttribute('class', stageClass(st).replace('step-final','step-0'));  // ② 되감기
  for (var k=1;k<=STEP_COUNT;k++) (function(k){
    timers.push(setTimeout(function(){
      el.setAttribute('class', stageClass(st).replace('step-final','step-'+k));
      setCaptionProgress(k);
      if (k===STEP_COUNT) { el.setAttribute('class', stageClass(st)); setCaptionProgress(99); }
    }, STEP_MS[k]));
  })(k);
}

function skip(st){ clearTimers(); render(st); }   // 무대 아무 데나 탭 = 즉시 끝
```

- **되감기는 타이머가 있을 때만** 일어난다 → Node 헤드리스는 `render()`의 최종 상태만 본다.
- `querySelectorAll` 미사용. DOM 접근은 **`getElementById` 전용**, id는 아래 각 무대의 표로 고정한다.
- `requestAnimationFrame` 미사용. 시간 진행은 `setTimeout` 한 종류로만.
- 진행/판정 문구는 **처음부터 DOM에 들어 있고**, 아직 안 온 단계만 CSS `opacity:.12`로 흐려진다
  (`display:none` 금지 — textContent 검사가 통과해야 한다).

### 0-2. 무대 그릇(360px 대응)

```html
<div class="stage-wrap" id="g_wrap">
  <svg id="g_stage" class="stage exp-g step-final" viewBox="0 0 720 400"
       role="img" aria-labelledby="g_ttl g_dsc" preserveAspectRatio="xMidYMid meet">
    <title id="g_ttl">그리피스 실험 무대</title>
    <desc id="g_dsc">주사기, 생쥐, 현미경 시야</desc>
    …
  </svg>
</div>
<ol class="stage-caption" id="g_cap" aria-live="polite"> … </ol>
```

```css
.stage-wrap{ overflow-x:auto; -webkit-overflow-scrolling:touch; padding-bottom:6px; }
.stage{ display:block; width:100%; min-width:560px; height:auto; touch-action:manipulation; }
```

- **viewBox 고정 + `min-width:560px` + 가로 스크롤 상자.** 폭 360px에서 무대는 줄어들지 않고 스크롤된다.
- 축소율 하한 560/720 = 0.78 → **무대 안 글자는 viewBox 단위 21 이상**(= 화면 16px 이상).
  일반 규칙: `무대 글자 크기 ≥ viewBox 가로폭 ÷ 34`.
- 무대 안에는 6자 이내 라벨만 둔다. **문장은 전부 무대 밖 HTML**(캡션·관찰표)에 둔다.

### 0-4. 애니메이션 기술 선택 (iOS Safari 안전)

- 이동·회전: **CSS `transform` + `transition`**만 사용. SVG `x/y/width/cx` 같은 기하 속성은 애니메이션하지 않는다(브라우저별 지원 편차).
  - 액체가 줄어드는 연출은 「흰색 와이퍼 사각형이 밀대와 함께 오른쪽으로 이동」으로 대체.
- 선이 그려지는 연출: `stroke-dasharray` + `stroke-dashoffset` transition (`pathLength="100"` 지정).
- 발광: `filter`(feGaussianBlur) 금지 — 태블릿에서 느리다. **동심 halo 원 2겹의 opacity 점멸**로 대체.
- `transform-box:fill-box; transform-origin:center;`를 회전하는 모든 SVG 그룹에 명시.

## 4. 방사성 표지 색·형태 규칙 (요구 3 — 색맹 학생 대응 포함)

| 구분 | ³⁵S (단백질 껍질) | ³²P (DNA) | 비표지 |
|---|---|---|---|
| **색** | `--yellow #B7791F` (흰 배경 대비 ≈4.6:1) | `--purple #7B4FB5` (≈6.0:1) | `#9AA3AE` |
| **표지 마커(형태)** | **▲ 삼각형** | **◆ 마름모** | 마커 없음 |
| **무늬(fill pattern)** | **점 무늬** `#pat-dots` (r=2, 간격 7) | **사선 무늬** `#pat-hatch` (45°, 간격 6, sw 2.5) | 무늬 없음 |
| **외곽선** | 실선 sw 3 | **파선** `stroke-dasharray:7 4` sw 3 | 실선 sw 2, 흐림 |
| **halo(발광)** | `#E7C77A` 2겹 동심 | `#C9AEE8` 2겹 동심 | 없음 |
| **문자 병기** | 무대·계수기·캡션에 항상 `<sup>35</sup>S` 병기 | 항상 `<sup>32</sup>P` 병기 | — |

규칙:
1. **색·형태·무늬·문자 4중 부호화.** 어느 하나만으로 정보를 전달하지 않는다.
   흑백 인쇄나 색맹 상황에서도 「점 무늬 + ▲」와 「사선 무늬 + ◆ + 파선」은 구분된다.
2. 표지된 파트는 무늬가 **있고**, 표지 안 된 파트는 무늬가 **없다** → 「어느 쪽을 표지했는가」가 색과 무관하게 읽힌다.
3. ³⁵S 실험에서는 껍질에만, ³²P 실험에서는 머리 속 DNA·주입 DNA에만 무늬가 들어간다. 둘을 동시에 표지하지 않는다.
4. 계수기·범례·관찰표에도 동일한 마커(▲/◆)를 그대로 쓴다 — 무대와 표의 부호가 어긋나지 않게 한다.
5. 무대 우상단에 **범례 박스** 고정: `▲³⁵S 단백질(점) / ◆³²P DNA(사선)`.

## 5. 접근성 (요구 4)

### 5-1. prefers-reduced-motion
```css
@media (prefers-reduced-motion: reduce){
  .stage *, .stage{ transition:none !important; animation:none !important; }
  .stage-caption li{ opacity:1 !important; }
}
```
JS도 이중으로 막는다 — `prefersReduced()`가 참이면 `CAN_ANIM=false` → `play()`는 `render()`만 하고 끝난다.
**되감기 자체가 일어나지 않으므로 깜빡임도 없다.**

### 5-2. 애니메이션 없이 같은 정보를 읽는 경로 3겹
1. **단계 캡션 `<ol aria-live="polite">`** — 위 표의 「학생이 읽어야 할 것」이 그대로 `<li>`로 들어간다.
   재생 중에는 아직 안 온 항목이 `opacity:.12`(텍스트는 DOM에 존재), 끝나면 전부 선명.
   reduced-motion·헤드리스에서는 처음부터 전부 선명.
2. **관찰 기록표(HTML `<table>`)** — 조건별 결과의 정본. 무대를 한 번도 못 봐도 이 표만으로 결론에 도달한다.
   → **헤드리스 회귀 검사는 이 표의 셀 텍스트를 본다.**
3. **SVG `<title>`/`<desc>`** — 상태가 바뀔 때 `desc.textContent`를 현재 장면 요약으로 갱신.
   `role="img"` + `aria-labelledby="…ttl …dsc"`.

### 5-3. 그 밖에
- 무대 안 글자는 viewBox 폭 ÷ 34 이상(= 화면 16px 이상). 문장은 무대 밖에 둔다.
- 탭 목표: 무대 전체가 스킵 대상, 재생 버튼은 별도 `<button style="min-height:48px;min-width:48px">`.
- `touch-action:manipulation`으로 더블탭 확대 지연 제거.
- 애니메이션 중에도 다음 버튼을 비활성화하지 않는다 — 탭하면 스킵 후 진행.
- 색만으로 정보를 전달하는 곳이 없다(§0-3, §4의 형태 규칙).
- 무대 배경은 흰색 고정, 텍스트 대비 4.5:1 이상.

## 7. 구현 체크리스트 (헤드리스 검사와 함께 볼 것)

- [ ] `setTimeout` / `clearTimeout` / `matchMedia` 사용부가 전부 `typeof` 가드 안에 있다
- [ ] `requestAnimationFrame` · `querySelectorAll` · `querySelector` 사용 0
- [ ] `render()`만 호출해도 무대 클래스·캡션·관찰표가 최종값이 된다 (검사가 보는 지점)
- [ ] 되감기(`step-0`)는 `CAN_ANIM`이 참일 때만 실행된다
- [ ] 각 재생 단위 총 시간 ≤ 3 000ms (그리피스 2 900 / 에이버리 2 900 / 허시체이스 2 800·2 900)
- [ ] 무대 탭 → `skip()` → 최종 상태 즉시
- [ ] 폭 360px에서 무대가 축소되지 않고 가로 스크롤된다(`min-width:560px`)
- [ ] 무대 안 글자 ≥ viewBox 폭 ÷ 34
- [ ] 난수 없음 — 균·콜로니·조각 좌표는 전부 상수 배열
- [ ] 학생 화면 문구가 전부 시험지 문체(`~하시오` / `-이다`), 이모지는 허용
