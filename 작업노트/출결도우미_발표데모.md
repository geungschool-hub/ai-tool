# 출결 도우미 발표용 데모 (demo.html)

> 작성: 2026-07-10 · 통합 허브 앱 소개 발표(다음 주) 대비

## 배경
출결 도우미는 유일하게 **기기 localStorage 저장** 앱이라 발표 기기에서 실제 출결 현황을 보여줄 수 없음(개인정보 문제도 있음). → **가상 데이터 자동 시딩 데모 버전**을 별도 파일로 제작.

## 파일·URL
- 파일: `attendance-checklist_mobile/demo.html` (index.html은 무수정, 복사본 가공)
- URL: `https://geungschool-hub.github.io/ai-tool/attendance-checklist_mobile/demo.html`
- 생성 방식: 빌드 스크립트로 index.html에서 자동 생성 (일회성, 스크립트는 스크래치 — index 업데이트 반영하려면 재생성 필요)

## 본 앱과의 분리 (같은 기기에서 열어도 실데이터 무접촉)
localStorage 키 전면 교체: `attendance_demo_v1` / `subject_att_demo_v1` / `att_mode_demo` / `attendance_zoom_demo` / `lbl_demo_*` / `notice_subject_demo` / `onboarding_demo_v1`. 서비스워커 등록도 제거(본 앱 PWA 캐시와 분리). 우하단에 "데모 · 가상 데이터" 빨간 리본 고정.

## 시딩 동작
- **날짜는 열 때마다 '오늘' 기준으로 재계산**(주말 건너뛴 학교일 오프셋) → 발표 당일에도 최신 상황처럼 보임.
- `attendance_demo_seed_date`에 시딩 날짜 저장 — **같은 날 안에서는 시연 중 조작 유지**, 날짜 바뀌면 초기 상태로 재시딩.
- 담임 모드: 가상 여학생 24명, 오늘 질병결석 1(문지유·나이스 미입력 배너), 생리통 월2회(12번 손민서), 체험학습·조퇴·지각 등 과거 기록, 증빙서류 D-4/D-5 미제출 2건, 누적현황 initialStats 포함.
- 교과 모드: 생명과학 A반(6명)·B반(5명) + 결과 기록 몇 건.
- 학생 이름은 전부 가상 (public repo 커밋 안전).
