# ⑤ 세 실험 잇기 — 논리 사슬 조립 활동 설계서

대상: 「유전물질을 찾아라」(생물의 유전 1-4) 단일 HTML 모의실험의 **⑤단계 = 핵심 산출물**
성취기준: 12유전01-05 (과학사적 연구 결과를 설명하는 **발표 자료** 제작) — 완성된 사슬표가 곧 발표 자료의 뼈대다.

---

## 0. 이 활동이 노리는 한 가지

세 실험을 **각각** 아는 것은 ②③④단계에서 이미 끝난다.
⑤단계가 가르치는 것은 **한 실험이 남긴 물음이 다음 실험의 물음이 된다**는 사실 하나다.

그래서 판의 구조를 이렇게 못 박는다.

> **n행의 「남은 질문」과 (n+1)행의 「답하려 한 질문」은 같은 문장이다.**

두 칸에 **글자 하나 다르지 않은 같은 문장**을 넣는다(쌍둥이 카드).
학생이 덱에서 "어? 이 문장이 두 장 있다"를 발견하는 순간이 이 활동의 아하 모먼트다.
설명으로 알려 주지 않는다 — **카드가 두 장이라는 사실로** 알게 한다.

## 1. 3×4 사슬판 — 정답 카드 12칸

열 머리글(상시 노출, 툴팁 포함):

| 열 | 머리글 | 툴팁(❓ 아이콘) |
|---|---|---|
| 1열 | **이 실험이 답하려 한 질문** | 이 실험을 시작하게 만든 물음이다. **물음표로 끝난다.** |
| 2열 | **한 조작** | 실험자가 **실제로 손으로 한 일**이다. 결과나 결론은 여기에 적지 않는다. |
| 3열 | **알아낸 것** | 관찰 결과와 거기서 곧바로 끌어낼 수 있는 결론이다. **관찰한 범위를 넘지 않는다.** |
| 4열 | **남은 질문** | 이 실험만으로는 답할 수 없어 **다음 실험에 넘긴** 물음이다. **물음표로 끝난다.** |

### 1행 — 그리피스 (1928, 폐렴균과 생쥐)

| 열 | 정답 카드 문장 | 자수 |
|---|---|---|
| ① 답하려 한 질문 | **죽은 세균의 유전형질이 살아 있는 세균에게 옮겨질 수 있는가?** | 34 |
| ② 한 조작 | **열처리로 죽인 S형균과 살아 있는 R형균을 섞어 생쥐에 주입하였다.** | 37 |
| ③ 알아낸 것 | **죽은 S형균의 무언가가 R형균을 S형균으로 바꾸었다(형질전환).** | 35 |
| ④ 남은 질문 | **형질전환을 일으킨 물질의 정체는 무엇인가? DNA인가 단백질인가?** | 36 |

### 2행 — 에이버리 (1944, 세포 추출물과 분해효소)

| 열 | 정답 카드 문장 | 자수 |
|---|---|---|
| ① 답하려 한 질문 | **형질전환을 일으킨 물질의 정체는 무엇인가? DNA인가 단백질인가?** ←🔗1행④와 같은 문장 | 36 |
| ② 한 조작 | **죽은 S형균 추출물에서 분해효소로 DNA·RNA·단백질을 각각 없앴다.** | 41 |
| ③ 알아낸 것 | **DNA를 없앤 경우에만 형질전환이 일어나지 않았다 → 그 물질은 DNA이다.** | 43 |
| ④ 남은 질문 | **DNA와 단백질을 섞이지 않게 갈라놓아도 같은 결론이 나오는가?** | 40 |

### 3행 — 허시·체이스 (1952, 박테리오파지와 대장균)

| 열 | 정답 카드 문장 | 자수 |
|---|---|---|
| ① 답하려 한 질문 | **DNA와 단백질을 섞이지 않게 갈라놓아도 같은 결론이 나오는가?** ←🔗2행④와 같은 문장 | 40 |
| ② 한 조작 | **단백질은 ³⁵S로, DNA는 ³²P로 표지한 파지를 대장균에 감염시켰다.** | 40 |
| ③ 알아낸 것 | **대장균 안에서 검출된 방사선은 ³²P뿐이었다 → 들어간 물질은 DNA이다.** | 43 |
| ④ 남은 질문 | **DNA는 어떤 구조이길래 그 안에 유전정보를 담는가?** → 판 밖 「다음 차시」로 | 31 |

### 이음매(쌍둥이 카드) 정리

| 이음매 | 문장 | 두 자리 |
|---|---|---|
| 🔗**1** | 형질전환을 일으킨 물질의 정체는 무엇인가? DNA인가 단백질인가? | 1행④ ↔ 2행① |
| 🔗**2** | DNA와 단백질을 섞이지 않게 갈라놓아도 같은 결론이 나오는가? | 2행④ ↔ 3행① |
| 🔗**3**(열린 고리) | DNA는 어떤 구조이길래 그 안에 유전정보를 담는가? | 3행④ ↔ **다음 차시** |

> 판정 규칙: 이음매 카드는 **정답 ID를 공유**한다. 학생이 두 장 중 어느 쪽을 어느 칸에 놓든 정답이다.
> 이 관대함이 의도다 — "두 칸이 같다"는 것을 손으로 확인시키는 것이 목적이므로 순서를 따지지 않는다.

### 이음매마다 붙는 「왜 이 물음이 남았는가」 툴팁 (💡, 상시 열람 가능·정답 비노출)

- 🔗1 : 그리피스는 **무엇인가 옮겨 갔다**는 사실만 보았다. 그 물질을 손에 쥐고 확인한 것은 아니었다.
- 🔗2 : 에이버리의 추출물에는 단백질이 **조금 남아 있을 수 있었다.** 당시 학자들은 그 점을 의심하였다.
- 🔗3 : DNA가 유전물질임은 밝혀졌으나, **네 종류 염기로 어떻게 정보를 담는지**는 아직 아무도 몰랐다.

### ★교사용 주의 (학생 화면에는 넣지 않음)

그리피스의 실제 연구 목적은 **폐렴 백신 개발**이었고 형질전환은 그 과정에서 발견되었다.
1행①의 「답하려 한 질문」은 **사슬을 보이기 위해 재구성한 물음**이다.
완성 화면 교사용 각주에 한 줄로 밝혀 둔다: 「과학사는 이렇게 한 줄로만 흐르지는 않았다. 이 판은 세 실험의 **논리**를 잇는 그림이다.」

## 2. 화면 시각화 — 사슬이 눈에 보이게

### 판 배치

```
        ①답하려 한 질문   ②한 조작    ③알아낸 것   ④남은 질문
1928  ┌──────────┬────────┬────────┬──────────┐
그리피스│          │        │        │  🔗1     │──┐
      └──────────┴────────┴────────┴──────────┘  │  ㄷ자 커넥터
1944  ┌──────────┬────────┬────────┬──────────┐  │  (판 오른쪽 여백 28px)
에이버리│  🔗1     │        │        │  🔗2     │──┼──┘
      └──────────┴────────┴────────┴──────────┘  │
1952  ┌──────────┬────────┬────────┬──────────┐  │
허시체이스│ 🔗2     │        │        │  🔗3     │──┘→ ▼ 판 밖 「다음 차시」 표지
      └──────────┴────────┴────────┴──────────┘
```

### 규칙 5가지

1. **같은 색 = 같은 물음.** 🔗1 두 칸 = `--amber #E67E22`, 🔗2 두 칸 = `--purple #7B4FB5`, 🔗3 = `--blue #1255A0`.
   나머지 8칸은 무채색 테두리(#BBB). **색이 들어간 칸은 판 전체에서 딱 짝수 개**라는 사실 자체가 힌트다.
2. **색만으로 구분하지 않는다.** 각 이음매 칸 왼쪽 위에 `🔗1` `🔗2` `🔗3` 라벨 병기(색각 이상·인쇄 대응).
3. **커넥터는 SVG ㄷ자 선.** 4열 칸 오른쪽 → 판 바깥 여백 → 아래 → 다음 행 1열 칸 왼쪽으로 진입, 끝에 화살촉.
   - 두 칸 중 하나라도 비면 **회색 점선 + 가운데 「?」 원**
   - 두 칸이 같은 카드로 채워지면 **해당 색 실선**으로 바뀌며 `stroke-dashoffset` 0.8s 흐름 애니메이션(위→아래)
   - 판정 결과 어긋나면 **붉은 점선 + 가운데 ⚡** (끊긴 사슬)
4. **세로 화면(태블릿 세로·폰)**: 3×4 그리드가 무너지면 행 단위 세로 스택으로 전환하고, 커넥터는 **직선 아래 화살표**로 단순화한다. 이음매 색·라벨은 그대로 유지한다.
5. **애니메이션 가드 필수.** `typeof requestAnimationFrame !== 'undefined'` / `typeof setTimeout !== 'undefined'` 로 감싸고,
   `@media (prefers-reduced-motion: reduce)` 에서는 전환 없이 최종 상태로 그린다. **결과 상태는 애니메이션과 무관하게 즉시 결정한다.**

## 3. 오답 카드 8장 (distractor)

각 카드는 **놓이고 싶은 자리(유혹 지점)** 가 정해져 있다. 아무 데나 안 맞는 문장은 오답 카드로서 값이 없다.

| # | 오답 카드 문장 | 유혹 지점 | 겨냥한 오개념 | 왜 틀렸는가(교사용) |
|---|---|---|---|---|
| **D1** | **그리피스는 형질전환을 일으키는 물질이 DNA임을 밝혔다.** | 1행③ | **결론 앞당기기** — 실험이 관찰한 범위를 넘겨 읽는다 | 그리피스는 「무엇인가 옮겨 갔다」까지만 보았다. 물질의 정체는 16년 뒤 에이버리의 몫이다. 이 카드를 놓으면 🔗1 이음매가 사라져 사슬 자체가 성립하지 않는다 |
| **D2** | **DNA 분해효소를 처리한 경우에만 S형균이 나타났다.** | 2행③ | **제거법 논리의 방향 뒤집기** — 없앴을 때 사라진다는 논리를 반대로 읽는다 | 결과가 정반대다. DNA를 없앤 경우에만 형질전환이 **일어나지 않았다.** 「있어야 할 것을 없애면 현상이 사라진다」가 제거법의 논리다 |
| **D3** | **대장균 안에서 ³⁵S가 검출되었으므로 단백질이 들어갔다.** | 3행③ | **상층액 ↔ 침전물 뒤바꿈** — 무거운 대장균이 가라앉는다는 원리 미적용 | ³⁵S는 상층액(껍질 쪽)에서만 검출되었다. S은 단백질에만, P은 DNA에만 있다는 표지 원리와 원심분리의 무게 논리를 함께 놓쳐야 나오는 문장이다 |
| **D4** | **파지의 유전물질은 언제나 DNA임이 이 실험으로 확인되었다.** | 3행③ | **과잉 일반화** — 채택 교과서 지도 Tip이 지목한 오개념 | 유전물질로 RNA를 쓰는 파지도 있다. 이 실험이 보인 것은 **이 파지에서** 대장균 안으로 들어간 물질이 DNA라는 사실이다 |
| **D5** | **열처리로 죽인 S형균만을 생쥐에 주입해 죽는지 확인하였다.** | 1행② | **대조군을 결정적 조작으로 착각** | 그리피스 (다) 조건은 대조군이다. 형질전환을 보이려면 **죽은 S형균 + 살아 있는 R형균**을 섞어야 한다. 대조군만으로는 아무것도 결론지을 수 없다 |
| **D6** | **³⁵S와 ³²P를 한 파지에 함께 표지해 대장균에 감염시켰다.** | 3행② | **분리 설계 원리 미이해** — 표지를 둘 다 넣으면 구분이 불가능하다 | 두 표지를 한 시료에 넣으면 어느 쪽이 들어갔는지 갈라 볼 수 없다. **따로 표지한 두 벌**을 만드는 것이 이 실험 설계의 핵심이다 |
| **D7** | **단백질은 아미노산 20종으로 이루어져 정보를 담기에 유리하지 않은가?** | 2행① 또는 1행④ | **시대의 통념을 실험의 물음으로 착각** | 1940년대 학자들이 실제로 품었던 생각이지만, 에이버리가 실험으로 답하려 한 물음은 아니다. 물음처럼 생겼다고 사슬의 고리가 되지는 않는다 |
| **D8** | **DNA는 어떻게 복제되어 다음 세대로 전달되는가?** | 3행④ | **「정체」 문제 ↔ 「복제」 문제 혼동** | 훌륭한 물음이지만 이 사슬이 남긴 물음이 아니다. 1952년의 다음 물음은 **구조**였고, 복제 방식은 구조가 밝혀진 뒤(1953~) 나온다 |

### 예비 오답 카드(난도 상향 시 추가 — 기본 덱에는 넣지 않는다)

- **S1** 「죽은 S형균의 껍질이 R형균을 덮어 S형균처럼 보이게 되었다.」 → 1행③ / **형질전환을 유전정보 전달이 아닌 「겉모습 덮어쓰기」로 이해**
- **S2** 「유전물질은 세포의 어느 부분에 들어 있는가?」 → 1행① / **유전물질의 「정체」 문제와 「위치」 문제 혼동**

## 4. 카드를 놓는 방식 — **탭-선택-탭-배치**를 권한다 (드래그 아님)

### 권고안

1. 덱(하단)에서 카드를 한 번 탭 → 카드가 들리며 상단 **「손에 든 카드」 sticky 트레이**에 문장이 고정 표시
2. 판의 빈 칸을 탭 → 그 칸에 놓임
3. 놓인 카드를 다시 탭 → 덱으로 회수
4. 손에 든 카드를 다시 탭하거나 「✋ 내려놓기」 → 선택 해제

### 드래그를 버리는 까닭 (태블릿 · 저사양 크롬북 기준)

| 근거 | 내용 |
|---|---|
| **입력 경로가 하나로 끝난다** | 드래그는 마우스(pointerdown/move/up)와 터치(touchstart/move/end)를 따로 다뤄야 하고, iOS Safari는 HTML5 DnD를 사실상 못 쓴다. 탭은 `click` 하나로 3기기 모두 동일 동작 |
| **스크롤 제스처와 충돌하지 않는다** | 3행 × 4열 + 15장 덱은 한 화면에 안 들어온다 → 세로 스크롤이 필수다. 터치 드래그는 스크롤을 막기 위해 `touch-action:none`을 걸어야 하고, 그러면 **카드를 잘못 눌러 잡은 채로는 화면을 못 내린다.** 실제 수업에서 손이 굳는 지점이 여기다 |
| **카드가 손가락에 가린다** | 25~45자 카드는 폭이 크다. 드래그 고스트가 손 밑에 들어가 **목적지 칸이 안 보인다.** 탭 방식은 손에 든 카드가 화면 맨 위에 고정돼 항상 읽힌다 |
| **저사양 크롬북 성능** | 드래그는 매 프레임 transform·hit-test → 프레임 드랍이 그대로 「카드가 안 잡힌다」는 체감이 된다. 탭은 상태 변화 두 번뿐 |
| **오조작 회복 비용** | 드래그 중 손을 떼면 카드가 어디로 갈지 학생이 예측하지 못한다. 탭은 잘못 놓아도 다시 탭 한 번 |
| **접근성·키보드** | Tab 이동 + Enter 선택/배치로 **같은 코드가 그대로 동작한다.** 드래그는 키보드 대체 UI를 따로 또 만들어야 한다 |
| **헤드리스 검증** | Node 검사 샌드박스에는 rAF·setTimeout이 없다. `click` 핸들러 직접 호출로 12칸 배치 전 과정을 검사할 수 있으나, DnD 이벤트 시퀀스는 재현이 어렵다 |

### 터치 규격

- 카드 최소 높이 **56px**, 좌우 패딩 12px, 폰트 **16px 이상**, 칸 최소 높이 **72px**
- 손에 든 카드가 있을 때만 빈 칸에 **점선 테두리 + 1.02배 확대** (놓을 수 있는 자리 표시)
- ★**열을 좁혀 주지 않는다** — 「이 카드는 3열용」 같은 하이라이트는 답을 알려 주는 것이므로 금지. 빈 칸은 **모두 똑같이** 후보로 보인다
- 덱은 셔플하되 **회차마다 같은 순서**(localStorage 시드 저장) — 새로고침 후 화면이 달라 보이면 학생이 혼란스럽다

## 5. 채점·피드백 — 답을 알려주지 않고 되돌아보게 하는 문구 4종

### 판정 시점

배치 중에는 **판정하지 않는다.** 12칸을 다 채우고 **「🔗 사슬 이어 보기」** 버튼을 누를 때 일괄 판정한다.
- 맞은 칸: 초록 테두리 + 🔒 고정(회수 불가)
- 틀린 칸: 카드가 덱으로 되돌아가고 **그 자리에 피드백 문구만 남는다**
- 시도 횟수는 **기록하지 않는다**(이 활동은 연습이다). 진행 배지는 「놓은 칸 N / 12」

### 문구 4종

**① 자리의 성격이 어긋났다 (열 오류 — 정답 카드이나 다른 열의 것)**
> 옳지 않다. 이 칸은 **「무엇을 물었는가」**를 적는 자리이다. 놓인 문장은 물음이 아니라 이미 알아낸 것을 말하고 있다. 문장이 물음표로 끝나는지 확인하시오. 🔎

*(열마다 앞 절만 바꾼 4변형)*
- 2열 → 「이 칸은 **실험자가 손으로 한 일**을 적는 자리이다. 놓인 문장은 한 일이 아니라 그 결과를 말하고 있다.」
- 3열 → 「이 칸은 **관찰에서 끌어낸 것**을 적는 자리이다. 놓인 문장은 아직 답하지 않은 물음이다.」
- 4열 → 「이 칸은 **이 실험이 답하지 못하고 남긴 물음**을 적는 자리이다. 놓인 문장은 이미 답이 나온 내용이다.」

**② 실험이 어긋났다 (행 오류 — 열은 맞으나 다른 실험의 문장)**
> 옳지 않다. 이 문장에 나오는 재료는 이 행의 실험에서 쓰지 않았다. 어느 실험의 재료인지 짚어 보고 행을 다시 고르시오. 👆

**③ 사슬이 끊겼다 (이음매 불일치 — 두 칸이 서로 다른 문장)**
> 옳지 않다. 지금 상태로는 앞 실험이 남긴 물음과 이 실험이 답하려 한 물음이 서로 다른 말을 한다. 두 칸을 위아래로 나란히 소리 내어 읽어 보시오. 🔗
*(동시에 해당 커넥터가 붉은 점선 + ⚡ 로 바뀐다 — 문구보다 이 그림이 더 세게 말한다)*

**④ 말이 지나치거나 뒤집혔다 (오답 카드)**
- 범위 초과형(D1·D4·D7):
> 옳지 않다. 이 실험이 실제로 관찰한 것만으로는 여기까지 말할 수 없다. 이 실험에서 눈으로 확인한 것은 무엇이었는지 되짚으시오. 🤔
- 뒤집힘·설계 오류형(D2·D3·D5·D6·D8):
> 옳지 않다. 어느 조건에서 무엇이 나타났는지가 반대로 되어 있다. 앞 단계 화면의 결과를 다시 확인하시오. 📌

### 절대 금지

- 「정답은 ○○이다」 식의 정답 제시 — **어떤 경우에도 하지 않는다**
- 「아깝다」 「거의 다 왔어」 같은 친근체·추임새 (이모지는 허용, 말투만 시험지 문체)
- 맞은 칸을 세어 점수·별점으로 환산하는 표시 (연습 활동이므로 정오를 기록하지 않는다)

### 막혔을 때의 도움 (요청형만)

같은 칸에서 3회 이상 틀리면 그 칸에 **❓ 버튼**이 생긴다. 누르면 **그 칸의 정답이 아니라 열의 성격 정의**만 다시 보여 준다.
(예: 「② 한 조작 = 실험자가 실제로 손으로 한 일. 결과·결론은 여기에 적지 않는다.」)

## 6. 완성 화면 — 사슬이 이어진 뒤

### 순서 (모두 setTimeout 가드, reduced-motion에서는 즉시 최종 상태)

1. 12칸이 모두 초록으로 잠긴다
2. 🔗1 → 🔗2 커넥터가 **위에서 아래로 순차 점등**(각 0.6s), 색이 회색 점선 → 앰버 → 퍼플 실선으로 바뀐다
3. 3행④에서 나온 화살표가 **판 밖 아래**로 빠져나가 「다음 차시」 표지에 닿는다
4. 판 위에 요약 배너가 뜬다

### 한 문장 요약 (배너)

> 🎉 **1928년의 「무엇인가 옮겨 갔다」가 1944년의 「그 무엇은 DNA이다」를 거쳐 1952년의 「세포 안으로 들어간 것도 DNA이다」에 이르렀다. 한 실험이 남긴 물음이 다음 실험이 답할 물음이 되었다.**

### 「그래도 남은 질문」 (판 밖, 홀로 놓인 카드)

```
        ┌────────────────────────────────────┐
   🔗3 →│  DNA는 어떤 구조이길래             │
        │  그 안에 유전정보를 담는가?        │
        └────────────────────────────────────┘
        이 물음에는 이 사슬의 어느 실험도 답하지 못하였다.
        ▶ 다음 차시 : DNA의 구조
```

- 다음 차시 예고는 **한 줄까지만.** 왓슨·크릭의 답을 여기서 미리 말하지 않는다(다음 차시의 물음을 죽인다).
- 「1953년, 이 물음에 답한 사람들이 나타난다」 정도의 한 줄 예고까지는 허용.

### 완성 후 버튼 4개

| 버튼 | 동작 |
|---|---|
| ✏️ **한 문장으로 다시 쓰기** | 자유 입력칸 1개(localStorage 저장). 발문: 「세 실험이 이어지는 논리를 한 문장으로 쓰시오.」 → ⑦ 정리하기로 이어진다 |
| 📄 **사슬표 보기(인쇄용)** | 12칸을 A4 한 장 표로 재배치. 커넥터는 굵은 ↓ 화살표 문자로 대체. **12유전01-05 발표 자료의 뼈대**로 그대로 쓴다 |
| ▶ **⑥ 연습 문항으로** | 다음 단계 이동 |
| 🔄 **처음부터 다시 하기** | 확인 대화상자: 「지금까지 놓은 카드를 모두 지우고 처음부터 다시 하시겠습니까?」 |

## 7. 난도 조절 — 몇 칸을 미리 채워 둘 것인가

### 미리 채우기의 원칙 3가지

1. **이음매는 절대 미리 채우지 않는다** — 단, **1행은 예외로 통째로 채운다**(아래 2번).
   🔗1·🔗2가 걸린 네 칸 중 학생이 채워야 할 칸이 하나도 없으면 이 활동은 할 이유가 없어진다.
2. **1행 4칸은 「완성 예시」로 통째로 채운다.** 열의 성격을 글로 설명하는 대신 **채워진 한 행을 보고 알게** 한다.
   덤으로, 1행④가 채워져 있으므로 학생은 덱에서 **똑같은 문장을 또 발견**하게 된다 → 쌍둥이 카드 규칙을 스스로 깨닫는다. 이것이 사슬 규칙 학습의 핵심 장치다.
3. **2열(한 조작)은 부담을 덜 때 먼저 푼다.** ②③④단계에서 학생이 직접 조작해 본 내용이라 인출이 가장 쉽고, 사슬 논리와는 거리가 멀다. 즉 **난도를 낮출 때 가장 먼저 채워 주는 열**이다.

### 3단계 프리셋

| 단계 | 미리 채운 칸 | 학생이 놓을 칸 | 덱 | 대상 |
|---|---|---|---|---|
| **1단계(도움 많음)** | 1행 4칸 **+ 2·3행 「한 조작」 2칸 + 3행④ 1칸** = **7칸** | **5칸** | 정답 5 + 오답 4 (D1·D2·D5·D7) | 진도가 느린 강좌, 남은 시간 10분 |
| **2단계(표준) ★기본값** | **1행 4칸** | **8칸** | 정답 8(쌍둥이 2쌍 포함 10장) + 오답 8 | 기본 |
| **3단계(도전)** | **1행① 1칸만** | **11칸** | 정답 11 + 오답 8 + 예비 2(S1·S2) | 빨리 끝낸 학생, 심화 |

- 미리 채운 칸은 **회색 배경 + 📌 아이콘 + 회수 불가**로 표시해 "내가 놓은 것"과 구별한다.
- 난도는 학생이 스스로 고른다. 상단에 「🔧 난도」 셀렉터를 두고 **기본값 2단계**로 시작한다.
- 바꾸면 판이 초기화되므로 확인 대화상자: 「난도를 바꾸면 지금 놓은 카드가 모두 지워집니다. 바꾸시겠습니까?」
- **12칸 전부 비우는 0단계는 만들지 않는다.** 열의 성격을 모른 채 15~19장을 훑는 순간 이 활동은 낱말 맞히기가 되고, 사슬은 보이지 않는다.

## 8. 구현 메모 (제작 담당자용)

### 데이터 구조

```js
const CHAIN = {
  rows: [
    { id:'griffith', year:1928, name:'그리피스',    material:['폐렴균','S형균','R형균','생쥐'] },
    { id:'avery',    year:1944, name:'에이버리',    material:['추출물','분해효소'] },
    { id:'hershey',  year:1952, name:'허시·체이스', material:['파지','대장균','³⁵S','³²P'] }
  ],
  cols: ['q','act','found','left'],           // 답하려 한 질문 / 한 조작 / 알아낸 것 / 남은 질문
  cards: [
    { id:'A1',  text:'죽은 세균의 유전형질이 …', slots:['griffith.q'] },
    …
    { id:'L1',  text:'형질전환을 일으킨 물질의 정체는 …', slots:['griffith.left','avery.q'], twin:true, link:1 },
    { id:'L2',  text:'DNA와 단백질을 섞이지 않게 …',     slots:['avery.left','hershey.q'],  twin:true, link:2 },
    { id:'D1',  text:'그리피스는 형질전환을 …', distractor:true, feedback:'over',  mis:'결론 앞당기기' },
    …
  ]
};
```
- `slots`가 배열인 것이 쌍둥이 카드 처리의 전부다. 덱에는 같은 `id`의 카드를 **2장** 넣는다(`L1a`,`L1b`).
- 판정: `card.slots.includes(placedSlot)` → 정답. 아니면 `card.slots[0]`의 열/행을 비교해 ①/② 문구 선택. `distractor:true`면 `feedback` 종류로 ④ 문구 선택. 두 이음매 칸의 카드 `id`가 다르면 ③ 문구.

### localStorage

- 키: `gene14_chain_v1` = `{ level:2, placed:{ 'avery.q':'L1b', … }, note:'학생이 쓴 한 문장', deckSeed:12345 }`
- **정오는 저장하지 않는다.** 놓인 카드 배치만 저장해 새로고침 후 화면을 복원한다.

### 헤드리스 검사 항목 (`_test_유전물질.js`에 추가)

1. 12칸 정답 배치 → 모두 정답 판정 + `chainComplete === true`
2. 쌍둥이 카드를 **뒤바꿔** 놓아도(L1a↔L1b) 정답 판정
3. 오답 카드 8장 각각 → 지정한 피드백 종류(`over`/`flip`)가 나오는가
4. 정답 카드를 다른 열/행에 놓았을 때 ①/② 문구가 갈려 나오는가
5. 이음매 두 칸이 다른 카드일 때 ③ 문구 + 커넥터 상태 `broken`
6. 난도 1·2·3단계 프리셋의 **미리 채운 칸 수** = 7 / 4 / 1
7. **말투 점검**: 화면 문자열 전수 검사 — 금지어(`좋아`,`맞아`,`해 보자`,`찾았어`,`거야`,`네가`,`우리가`) 0건, 지시문은 `~하시오`로 끝남, 확인 대화상자는 `하시겠습니까?`
8. 애니메이션 없이(setTimeout·rAF 미정의) 완성 판정이 **즉시** 나오는가
9. 용어 표기 검사: `폐렴쌍구균`(단독 사용) 0건, `쥐`(생쥐 아닌 단독) 0건, `티민`·`시토신` 0건
