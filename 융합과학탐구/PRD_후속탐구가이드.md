# PRD — 「후속 탐구 보고서 가이드」 (3학년 융합과학탐구 수행평가 웹앱)

작성 2026-08-12 · 기반: `과학탐구보고서_작성법.html`(1학기 생명과학 보고서 가이드) 개조
★2026-08-12 범위 변경: **계획서(수행①)는 교사가 별도 양식으로 직접 제작** — 이 앱은 **후속 탐구 보고서(수행②) 전용**.

## 0. 배경과 목표

### 무엇을 만드나
1학기 보고서 작성법 가이드(단일 HTML 웹앱)를 **후속 탐구 보고서 작성·제출 도구**로 개조한다.
학생은 이 앱에서 ①1학기 탐구와 아쉬운 점을 정리하고 → ②서론 → ③본론 → ④결론을 단계별로 쓰고 → ⑤자기점검 후 앱에서 바로 제출한다.

### 왜 (핵심 컨셉)
- **후속 탐구 보고서 = 앞선 탐구의 아쉬운 점에서 다시 시작하는 보고서.**
  서론은 "1학기에 뭘 했고 뭐가 아쉬웠나"로 열고, 고찰은 "그 아쉬움이 보완되었나"로 닫는다.
- 3학년(수능 준비로 바쁨) → 화면 5개, 쓰는 칸 9개로 압축. 앱이 입력을 취합해 **완성된 보고서 전문**을 만들어 준다.

### 확정 평가계획과의 연결
| 수행평가 | 배점 | 성취기준 | 이 앱과의 관계 |
|---|---|---|---|
| ① 후속 탐구 계획서 | 50점 (A50~E15) | 12융탐01-05 | **앱 범위 밖** — 교사 자체 양식 |
| ② 후속 탐구 보고서 발표 | 50점 (A50~E15) | 12융탐02-02 | **이 앱** — 보고서 작성~제출 전 과정 |
- 표절 시 0점 → 인용·출처 압축 안내와 경고를 앱에 유지.
- 발표자료(PPT 등)는 받지 않음. **제출물은 앱 제출 보고서가 전부.**

### 결정 사항 (2026-08-12 교사 확정)
1. 계획서는 교사 양식 / **보고서만 앱으로 제출** (메일 배관 없음).
2. 마감일은 앱에 박지 않음(실제 목표 8/31 이전, 독려는 구두). 마감 처리는 `REPORT_CLOSED` 플래그.
3. 진단·체크리스트는 자기점검용(채점 A~E와 명시 연계 안 함).
4. 배포 폴더명 **`yoonghob-guide`** · 과학허브 카드 등록 안 함 · **URL만 따로 전달**:
   `https://geungschool-hub.github.io/yoonghob-guide/`
5. 1학기 탐구의 디지털 기록 없음(제출데이터 67건은 전원 2학년 — 학번 확인) → 1학기 요약·아쉬운 점은 **학생 자기 입력**.

## 1. 학생 흐름 (5화면)

1. **🧭 개관·재료** — 후속 보고서란 무엇인가(구조표 6칸) + 입력 3칸: 1학기 탐구 한 줄 요약 / 아쉬웠던 점 / 후속 탐구 질문. 좋은/나쁜 예시로 "새 주제로 새는 것"을 막는다.
2. **✍️ 서론 쓰기** — 서론 3요소(1학기 요약→아쉬운 점→이번에 알아볼 것)를 한 문단으로. 입력 1칸.
3. **🔬 본론 쓰기** — 입력 3칸: 무엇을 어떻게 했나 / 알아낸 것(사실+출처) / 고찰(뜻 해석+**아쉬운 점이 보완됐나**). 인용 압축 안내(3종)+표절 0점 경고 포함.
4. **🔍 결론 쓰기** — 입력 2칸: 후속 질문에 대한 답+남은 한계 / 참고 자료 목록.
5. **✅ 점검·제출** — 보완 확인형 체크리스트 10항목 + 취합된 보고서 전문 미리보기 + 학번·이름·제목 + [보고서 제출하기](Firebase) + PDF/전체 복사.

관통 예시: 카페인 후속 탐구 서사 — "1학기 문헌조사로 '늦은 카페인이 수면 방해' 결론 → 아쉬움: 직접 확인 못 함 → 후속: 우리 반 설문으로 확인".

## 2. 제작 5단계
1. **콘텐츠 재설계** — 5화면용 데이터 JSON 전면 재작성(위 흐름·예시·체크리스트), 평어체 유지. 완료 기준: 교사 검수.
2. **작성 화면 구현** — 화면 1~4(step 렌더러 재사용 + 구조표·인용 블록 확장), localStorage 키 신규(`yoonghob_*`).
3. **점검·제출 화면 구현** — 체크리스트·보고서 취합(buildReportText)·PDF(printdoc 재사용).
4. **제출 배관·교사 화면** — RTDB `yoonghobReports/{학번}` (공개 규칙, 무인증 패턴 동일), 제출 12초 타임아웃, 학번 5자리 검증. `admin.html` 개조(제목·ROOT·salt·CSV). ★규칙은 상위집합 파일에 경로 명시 추가 후 deploy — **배포 전 라이브 규칙 확인**(다른 앱이 규칙을 바꿨을 수 있음).
5. **검증·배포** — JSON 파싱/`node --check`/헤드리스 스샷, `긍스쿨 허브/yoonghob-guide/`로 복사·push, 라이브 200 확인, **교사 브라우저 왕복 제출 테스트**. `_제출데이터/`(2학년 실명) gitignore 등록.
