## 판독 방법 (창체 세특 때와 동일 — 검증 완료)

```bash
python -c "import fitz; d=fitz.open(r'...pdf'); p=d[N-1]; pm=p.get_pixmap(matrix=fitz.Matrix(2,2)); pm.save(r'...png')"
```
그 PNG를 Read 도구로 읽으면 손글씨가 선명하게 판독된다(2배율로 충분, 흐리면 3~4배율 + 부분 확대).
`rot=270`은 PyMuPDF가 렌더 시 자동 보정하므로 따로 회전시킬 필요 없다.
여러 쪽의 헤더만 잘라 세로로 이어 붙인 '대지(contact sheet)'를 만들면 **한 장으로 반 전체 학번·이름 매핑**을 확인할 수 있다(PIL 사용, 검증됨).
