## ③ DNA 복제 모의실험 (dna-sim 예정) — 계획

**교과서 활동**(p.48 탐구, 부록 137쪽 종이모형의 웹화): ①모형 준비 ②오른쪽→왼쪽으로 풀린다고 가정, 반 정도 잘라 두 가닥 분리 ③주형에 상보 뉴클레오타이드를 순서대로 붙이고 합성 방향 화살표 표시 ④나머지도 풀어 2개의 이중나선 완성.
정리하기: 1) 복제된 2개 DNA 비교 2) 위/아래 가닥에 붙인 방향과 까닭 3) 오류 삽입 시 수선 4) 반보존적 복제의 의미·장점(모둠 발표).

**부록 137쪽 실제 서열 (PDF 좌표 추출·상보성 검증 완료, 32bp)**
- 위(왼) 가닥 5′→3′: `TACCGTAAACAGGTATCATGCGGTCTCCCGAC`
- 아래(오른) 가닥 3′→5′: `ATGGCATTTGTCCATAGTACGCCAGAGGGCTG`
- 종이 조각: A·T·G·C 각 16개. 색 = **A 빨강 · T 파랑 · G 초록 · C 노랑** (앱에서도 동일 색으로).

**설계 골자**
- 복제 분기점(fork)이 오른쪽→왼쪽으로 열리는 가로 타일 스트립. 학생이 A/T/G/C 버튼을 탭해 상보 뉴클레오타이드 삽입(오답 = 흔들림 피드백 + 오답 카운트).
- 위 주형 = 선도 가닥(연속, 풀리는 방향), 아래 주형 = 지연 가닥(조각 합성 후 「연결효소」 버튼으로 연결) — 교과서 p.47 수준(프라이머·효소는 용어만).
- 64회 탭 방지: 일정 구간 직접 합성 후 「⚡나머지 자동 합성」 허용.
- 완성 화면: 딸 DNA 2개, 원래 가닥/새 가닥 배지 → 반보존적 시각 확인.
- 오답 카운트를 정리 3(수선)과 연결: "잘못 붙인 N개를 잘라내고 다시 붙였다 = 세포의 오류 수선".
- 확장(더 해보기): **메셀슨·스탈**(p.46 본문 연계) — 보존적/반보존적/분산적 모델을 고르면 1·2회 복제 후 원심분리 띠 예상을 그려 주고 실험 결과와 대조 → 반보존적만 일치.

## ④ 단백질합성 모의실험 (protein-sim 예정) — 계획

**교과서 활동**(p.66~67 탐구, 부록 138쪽 모형의 웹화): ①모형 오리기 ②주형 가닥과 상보인 mRNA 염기서열 적기(=전사) ③라이보솜 홈에 mRNA 끼워 P자리에 개시코돈 ④개시코돈과 상보인 tRNA를 P자리에 ⑤A자리 코돈과 상보인 tRNA ⑥P자리 아미노산을 잘라 A자리 tRNA의 아미노산에 풀로 붙이고(=펩타이드결합) 라이보솜을 3′쪽으로 이동, A자리 tRNA를 P자리로 ⑦다음 코돈 반복 ⑧종결코돈이 A자리에 오면 전부 분리.
정리하기: 1) 전사/번역 단계 구분 2) 풀로 붙임=펩타이드결합 3) mRNA 서열·아미노산서열 적기 4) 중심원리 유전정보 흐름 설명.
말풍선 주의: 실제는 소단위체에 mRNA+개시 tRNA 결합 후 대단위체 결합 — 탐구 편의상 결합된 라이보솜 사용(앱에도 이 주석 넣기).

**부록 138쪽 실제 데이터 (검증 완료)**
- 주형 가닥 DNA 3′→5′: `TACCATATGGTATCATGCCTCCCGACCATC` (30nt)
- mRNA 5′→3′: `AUGGUAUACCAUAGUACGGAGGGCUGGUAG` (코돈 10개)
- 폴리펩타이드: 메싸이오닌–발린–타이로신–히스티딘–세린–트레오닌–글루탐산–글라이신–트립토판 + 종결(UAG, tRNA 없음)
- tRNA 9종(카드에 안티코돈 표기 그대로): 메싸이오닌 UAC · 발린 CAU · 타이로신 AUG · 히스티딘 GUA · 세린 UCA · 트레오닌 UGC · 글루탐산 CUC · 글라이신 CCG · 트립토판 ACC — 각 1회씩 정확히 사용됨.
- 라이보솜: E·P·A 자리 표기.
- 코돈표는 p.62(해보기)에 전체 64개·한글 아미노산명 — 앱에 접이식 패널로 내장(02-02 "유전 부호 표를 사용하여 해독"이 성취기준이므로 필수).

**설계 골자**
- 1단계 전사: 주형 DNA 타일 아래에 A/U/G/C(+T 함정 버튼: "RNA에는 타이민이 없어요→유라실!") 탭으로 mRNA 완성. 일부 직접 후 자동 전사 허용. U는 별색(보라)으로 T(파랑)와 대비.
- 2단계 번역: E·P·A 라이보솜이 mRNA 위를 이동. A자리 코돈 하이라이트 → tRNA 카드 9장(안티코돈+아미노산명) 중 선택 → 도킹 → 펩타이드 사슬 구슬로 성장 → 이동 반복 → UAG에서 "결합할 tRNA가 없다" → 종결·분리 연출.
- 확장(더 해보기, p.62 ③ 연계): mRNA 염기 하나를 탭해 바꾸는 **돌연변이 모드** → 자동 재번역 → 원래 펩타이드와 대조(같음/아미노산 교체/조기 종결 자동 판정).
