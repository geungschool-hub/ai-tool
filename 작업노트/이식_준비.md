## 3. 이식 절차 (5단계)

```
① 읽기      외부 앱에서 대표 함수 grep -n → 로직·UI·데이터 형태 파악 (복붙 금지, 개념만)
② 자리 정하기 위 2-2 확장 지점 표에서 꽂을 곳 결정. 데이터가 필요하면 normItem/ensureAreas에 기본값
③ 구현      Edit 국소 치환만. 한글 주석으로 '왜'를 남긴다(교사가 나중에 혼자 읽는다)
④ 검증      node --check → 테스트 7종 → 필요하면 전용 test_*.js 신설
⑤ 배포      index.html → 긍스쿨 허브/saengbu/ 복사 → 커밋·푸시
```

**검증 명령**
```
cd "E:\AI tool\생기부_통합"
awk '/^<script>$/,/^<\/script>$/' index.html | sed '1d;$d' > _c.js && node --check _c.js && rm _c.js
cd _test
node test_regress.js && node test_step1.js && node test_records.js && node test_step2.js \
  && node test_period.js && node test_group.js && node test_synth.js
```
→ **114건 전부 통과**해야 한다. 파일 위생: 전 줄 CRLF · NUL 정확히 1개.

**배포**
```
cp index.html "..\긍스쿨 허브\saengbu\index.html"   # md5 일치 확인
cd "..\긍스쿨 허브\saengbu" && git add index.html && git commit && git push origin main
```
라이브 = https://geungschool-hub.github.io/saengbu/ (safe.directory 해제 완료 → 그냥 푸시하면 됨)

## 4. 기능별 이식 난이도 예상

지목이 오면 이 표로 즉시 "얼마나 걸리는지" 답한다.

| 난이도 | 기능 | 근거 |
|---|---|---|
| **쉬움 (~30분)** | 학생 간 중복 검사(#10) · 경고 무시 관리(#5) · 금지어 사용자 편집(#4) · 비밀번호 잠금(#17) · 폰트배율(#18) | 기존 확장 지점 1~2곳만 건드림. 데이터는 localStorage 키 1개 추가 |
| **보통 (~1~2시간)** | NEIS 입력 큐(#6) · 섹션 모드(#9) · 표현 사전·즐겨찾기(#12) · 저장소 건강 점검(#20) · 사용설명서(#19) | 새 모달 1벌 + 상태 필드. 렌더 파이프라인 손댐 |
| **어려움 (반나절+)** | XLSX 명렬 업로드(#7) · 엑셀 내보내기(#8) · docx/hwpx 읽기(#22) · 학년도 아카이브(#13) | ★**외부 라이브러리(SheetJS 등) 필요** — 단일 HTML·오프라인 원칙과 충돌. 인라인 번들 or CDN 여부를 먼저 정해야 함 |
| **어려움 (설계 선행)** | AI 문구 검토·일괄 검토(#1) | 검토 결과 스키마·자동 수정 적용 규칙·비용(반 전체 호출) 설계가 먼저 |
| **중간, 단 브라우저 제약** | 폴더 지정 자동백업(#14) | File System Access API — Chrome/Edge만. Safari·모바일 미지원. USB 오가는 사용자에겐 가치 큼 |

### 먼저 물어봐야 할 것
- **#7·#8·#22**: 외부 라이브러리를 쓸 것인가? 지금은 **의존성 0·오프라인 동작**이 원칙이다. SheetJS를 인라인하면 파일이 수백 KB 커진다.
- **#1**: 반 전체 AI 검토는 학생 수만큼 API 호출 = 비용. 1명씩만? 일괄?
- **#13**: 학년도 아카이브는 스키마에 `year` 축이 생긴다 → 마이그레이션 설계 필요. 다른 것보다 뒤에 두는 게 안전.
