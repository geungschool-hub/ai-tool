# ☀️ 7반의 방학 라이프

7반 여름방학 프로그램 웹앱 (2026.7.22 ~ 8.10)

- **여름 독서** — 방학 중 읽은 책을 자유롭게 기록하고 한 줄 소감을 남깁니다.
  읽은 책 중 한 권을 골라 "독후감 선택"을 눌러 두면 개학 때 그 책으로 독후감을 제출합니다.
- **7반 셋로그** — 하루에 한 명씩 배정된 "주인공"이 매 정각(07시~23시)마다
  10초 내외의 짧은 영상으로 자신의 하루를 기록합니다.
  영상 등록 시각은 서버(한국 시간) 기준으로 검증되므로 기기 시간을 바꿔도 소용없습니다.

학생은 **학번 + 이름 + PIN(숫자 4~6자리)** 으로 가입하고, 이후에는 학번 + PIN으로 로그인합니다.

## 폴더 구성

```
supabase/schema.sql   ← Supabase에 한 번 실행하는 DB 스키마
web/                  ← 배포할 웹앱 (index.html, config.js, style.css, api.js, app.js)
```

## 설치 (약 15분)

### 1. Supabase 프로젝트 만들기 (무료, 카드 등록 불필요)

1. https://supabase.com 에서 가입 → **New project**
2. Region은 **Northeast Asia (Seoul)** 선택, DB 비밀번호는 아무거나 정해서 따로 메모
3. 프로젝트가 만들어지면 왼쪽 메뉴 **SQL Editor** → `supabase/schema.sql` 파일 내용 전체를
   복사해 붙여넣고 **Run** (초록색 Success가 나오면 성공)

### 2. 앱과 Supabase 연결

1. 대시보드 왼쪽 **Settings → API** 에서
   - `Project URL`
   - `anon public` 키
   를 복사합니다.
2. `web/config.js` 를 열어 두 값을 붙여넣습니다.

### 3. 배포 (링크 만들기)

가장 쉬운 방법 — **Netlify Drop** (무료, 가입만 하면 됨):

1. https://app.netlify.com/drop 접속
2. `web` 폴더를 통째로 드래그 & 드롭
3. 생성된 링크(`https://….netlify.app`)를 학생들에게 공유

> 로컬에서 미리 테스트하려면: `web` 폴더에서 `python -m http.server 8000` 실행 후
> 브라우저에서 `http://localhost:8000` 접속.
> (카메라 녹화는 `localhost` 또는 `https` 에서만 동작합니다. `file://` 로 열면 안 돼요.)

### 4. 선생님 계정 만들기

1. 배포된 앱에서 "처음 왔어요"로 가입합니다. (학번 자리에 예: `teacher`)
2. Supabase **SQL Editor**에서 아래 한 줄을 실행합니다.

```sql
update public.students set is_teacher = true where student_no = 'teacher';
```

3. 앱에서 로그아웃 후 다시 로그인하면 하단에 **관리** 탭이 생깁니다.

### 5. 셋로그 배정

**관리** 탭에서 7/22~8/10 각 날짜에 학생을 배정합니다.
가입한 학생만 목록에 나오므로, 방학 전에 학생들에게 먼저 가입시키는 것을 추천합니다.

## 선생님 권한으로 할 수 있는 일

- 날짜별 셋로그 주인공 배정/변경
- PIN을 잊은 학생의 PIN 초기화 (임시 PIN이 화면에 표시됨)
- 부적절한 책 기록/영상 삭제 (모든 게시물에 삭제 버튼이 보임)
- 셋로그 영상 업로드 (배정과 무관하게 가능 — 시연/테스트용)

## 알아두면 좋은 것

- **저장 용량**: Supabase 무료 요금제는 파일 저장 1GB, 월 전송량 5GB입니다.
  10초 영상은 보통 2~4MB라서 방학 전체(20일 × 17슬롯)로도 1GB 안에 충분히 들어가지만,
  학생들이 영상을 아주 많이 돌려보면 전송량이 먼저 소진될 수 있어요.
  대시보드 **Settings → Usage** 에서 확인할 수 있습니다.
- **영상 삭제**: 앱에서 영상을 삭제하면 목록에서는 사라지지만 저장소 파일은 남을 수 있습니다.
  방학이 끝난 뒤 대시보드 **Storage → videos** 버킷에서 정리하면 됩니다.
- **개인정보**: 링크를 아는 사람은 누구나 반 친구들의 이름·책 기록·영상을 볼 수 있습니다.
  링크는 반 학생들에게만 공유하고, 외부에 올리지 않도록 안내해 주세요.
  방학 프로그램이 끝나면 Supabase 프로젝트를 삭제(또는 일시정지)하는 것을 추천합니다.
- **지원 브라우저**: 카메라 녹화는 최신 크롬/삼성인터넷/사파리에서 동작합니다.
  녹화가 안 되는 기기는 "앨범에서 올리기"로 촬영해 둔 영상(12초 이하)을 올리면 됩니다.

## 설정 바꾸기

`web/config.js` 에서 방학 기간, 셋로그 슬롯 시간대(기본 07~23시), 영상 최대 길이를
바꿀 수 있습니다. 단, **날짜·시간 규칙의 실제 검증은 서버에 있으므로**
`supabase/schema.sql` 의 `add_video` 함수 안 날짜/시간 조건도 함께 바꿔야 합니다.
