## 1. ★화면 뼈대 — 위는 활동, 아래는 문항

**2026-08-26 교사 지시: 하단부는 앞으로도 「💪 더 풀어 보기 + ⑤ 정리하기」로 간다.**

```
머리   제목 · 진행 배지(교사용 5연타) · 태그 · 진행 레일
①     읽고 들어가는 카드 (도입 문항 1개까지)
②③④  조작 카드 — 각각 [무대 + 조작 + 결론 문항], 앞을 마쳐야 다음이 열린다
💪     더 풀어 보기   — 선택형 4문항쯤(난도 표시). **풀지 않아도 활동은 완료된다**
⑤     정리하기       — 서술형 3 + 창의력 1 + 스스로 평가하기 3줄
바닥   🔄 처음부터 다시 하기 · 출처·성취기준 한 줄
```

### 하단부 두 카드의 성격이 다르다 — 섞지 말 것
| | 💪 더 풀어 보기 | ⑤ 정리하기 |
|---|---|---|
| 형식 | 선택형 (즉시 피드백) | 서술형 + 자기평가 |
| 잠금 | 본 활동을 마쳐야 열린다 | **처음부터 열려 있다** |
| 완료 판정 | **들어가지 않는다** (안 풀어도 완료) | 들어가지 않는다 |
| 노리는 것 | 활동 하나가 아니라 **활동 사이·비틀기**를 묻는다 | 말로 옮겨 정리 |
| 난도 | 중 2 · 상 2 쯤. 상 문항엔 **힌트 2단** | — |

- 모범답안은 **자수를 채워야 열린다**(`w.min`). 공백만으로는 안 열린다.
- 서술형 발문 아래 「답안에 반드시 들어가야 할 것」(`need`)을 늘 붙인다.
- 자기평가는 **지식·이해 / 과정·기능 / 가치·태도** 3줄 고정(교과서 「스스로 평가하기」 형식).

## 2. ★2단 배치 — 자료는 왼쪽, 조작은 오른쪽

```
.card.split > .panes > .pane-l (자료: 범례·무대·연출막대·결과표)
                     > .pane-r > .pr-do (조작: 설명·지시·칩·단추)
                              > .pr-q  (문항)
```

- 경계는 **1180px**. `1179px` 로 정수로 끊지 말 것(1179~1180 사이 소수 폭이 두 규칙 어디에도 안 걸린다).

## 3. ★무대 애니메이션 — chromolab 방식 (1-5 에서 확립)

교사가 지목한 정본은 **chromolab**(`/f/과학/생명과학/과학허브/chromolab`, React+framer-motion)이다.
그것이 하는 일은 하나다 — **물체마다 `key` 를 고정해 두고 위치만 애니메이션한다.**

### 하지 말 것 — 국면마다 다시 그리기
```js
// ✗ 국면이 바뀔 때마다 innerHTML 을 새로 넣으면 노드가 새로 생겨
//   CSS transition 이 걸리지 않는다. 물체가 「튀어나온다」.
setHTML('stage', stageSvg(id, phase));
```

### 할 것 — 한 번 짓고 속성만 바꾸기
```js
var mounted = null;
function render(){
  if (mounted !== id){ setHTML('stage', stageSvg(id)); mounted = id; }  // 한 번만 짓는다
  applyPhase(id);                                                       // transform·opacity 만
}
```
- 물체마다 `<g id="rs_s_<key>" class="rmove">` — **이 <g> 는 다시 만들어지지 않는다.**
- `.rmove{transition:transform .85s cubic-bezier(.4,0,.2,1), opacity .45s ease;}`
- ★전환은 **SVG `transform` 속성**에 건다(CSS transform 이 아니다). 속성에도 transition 이 걸린다.
- `prefers-reduced-motion` 에서 `transition:none`.
- `resetAll()` 에서 `mounted = null` 로 되돌린다.

### 순수 함수로 갈라 두기 — 검사가 물 수 있게
```js
repFrame(id, ph)   // 국면 → 놓인 물체 목록 { stage:'assembled'|'separate'|'synth', duplexes:[…] }
repLayout(id, ph)  // 국면 → 물체마다 {x, y, op} + 라벨·자취·캡션.  ★검사는 이것을 문다
applyPhase(id)     // 위 결과를 DOM 속성에 바른다.  DOM 없이도 로직을 검사할 수 있다
```
문자열 grep 으로 무대를 검사하지 말 것 — 레이아웃 함수를 직접 무는 것이 훨씬 강하다.

### 「대본」으로 정체성을 적는다
```js
var REP_CAST = {
  semi:{ dup:'unzip',
    G0:[['A','B']], G1:[['A','n1'],['n2','B']],
    G2:[['A','n3'],['n1','n4'],['n5','B'],['n2','n6']] }
};
```
**같은 key 가 세대를 건너 이어지면 그 물체는 미끄러져 이동한다.** 끊기면 사라졌다 새로 생긴다.
→ 대본이 곧 「어버이 가닥이 어떻게 되는가」라는 활동의 답이 된다.
⚠ **칸의 값(H/L)은 대본에 적지 않는다** — `MODELS` 에서 읽는다. 정본은 하나여야 한다.
검사가 「대본과 MODELS 가 일치하는가」·「같은 key 는 세대가 바뀌어도 값이 같은가」를 문다.

### 물체가 놓이지 않는 국면
**나타날 자리에 투명하게** 둔다. 그래야 없는 데서 날아오지 않고 제자리에서 스르르 나타난다.
(가장 가까운 「놓이는 국면」의 좌표를 찾아 `op:0` 으로 준다.)

### 지나간 세대는 자취 + 혈통선으로
물체가 아래로 이동해 버리면 윗줄이 텅 빈다. **흐린 사본 + 점선 혈통선**을 남겨 가계도처럼 읽게 한다.
chromolab 의 방추사가 하던 몫이다.

## 4. ★국면 설계 — 한 국면에 한 사건

> 2026-08-26 교사: 「**각 주형 가닥이 나뉘어진 다음에 새 가닥이 합성되는 두 과정을 명백히 구분**시켜 놓으면 좋겠다.」

한 국면에 두 사건을 넣으면 뭉개진다. 1-5 는 복제를 **① 분리 → ② 합성**으로 갈랐다(6국면 → 8국면).

- **분리 국면에는 그 단계의 새 물체를 아예 그리지 않는다.** 이것이 갈라짐의 전부다.
- 국면 이름에 **①·②로 차례**를 박는다(`① 두 가닥이 갈라진다` / `② 새 가닥이 합성된다`).
- 덤: 갈라지지 않는 모델(보존적)은 **분리 국면에 아무 일도 안 일어나는 것**이 그대로 보인다.

### ★진행 중에는 그 단계의 「결과」 표시를 내린다
> 2026-08-26 교사: 「**1세대의 결과 그림과 설명이 1세대의 복제가 시작된 후에도 여전히 남아 있어서** 어색하다.」

자취·혈통선·행 이름·물체 이름표·결과 표·결과 그림을 **조립이 끝난 국면에만** 보인다.
```js
var ASSEMBLED = { 0:0, 1:0, 4:1, 7:2 };   // 국면 → 완성된 세대. 나머지는 진행 중이다
```
- 진행 중인 물체에 **이름표를 붙이지 않는다** — 아직 그것이 아니므로 거짓말이 된다.
- 결과 표·결과 그림의 공개 시점도 같은 표를 따른다.

### 연출 제어 막대는 필수 (1-4 교사 지시)
`⏮ 처음부터 · ◀ 이전 · ▶ 다음 · ⏩ 끝까지` + 「단계 이름 n / N」.
- **`aniLast` 는 상수가 아니라 함수**여야 한다. 무대마다 국면 수가 다르다.
- 결과는 **연출과 무관하게 즉시 확정**된다. `setTimeout` 이 없는 환경(헤드리스 검사)에서도 결과가 난다.
- 떠나는 무대는 **완료 국면으로 되돌리고 다시 그린다** — 안 하면 중간 그림에 얼어붙는다.

## 5. ★시각 부호화 — 뜻이 둘이 되지 않게

| 시각 요소 | 뜻 | 규칙 |
|---|---|---|
| **위치(높이)** | 값(밀도·크기…) | 값에서 **계산**한다. 그려 넣지 않는다 |
| **굵기·크기** | **개수** | **개수에 정비례.** 절대 「분율」로 쓰지 말 것 ↓ |
| **색** | 종류 | 아래 색 규약 |
| 색의 진하기 | 두 종류의 섞임 정도 | 섞인 것은 **한 덩어리**로. 칸으로 쪼개지 말 것 |

### ⚠ 굵기를 「분율」로 쓰면 앱이 오개념을 심는다 (2026-08-26 교사 지적)
> 「P세대 띠 1개의 굵기가 2세대 띠 1개보다 월등히 굵어서… **P세대 띠 1개의 굵기를 2세대 띠 1개랑 같게** 해야 오개념이 안 생기겠는데?」

분율로 그리면 **1개(전체의 100%)가 2개(전체의 50%)보다 굵다.**
화면에는 「굵기 = 양」이라 써 놓고 정반대를 보여 주게 된다.
→ **`t = k·n`**(개수에 정비례). 그러면 세 가지가 한꺼번에 맞아떨어진다.

- 서로 다른 세대의 **같은 개수는 같은 굵기**다.
- 개수가 그대로면 **세대가 지나도 굵기가 그대로**다 ← 이게 오개념을 그림이 스스로 반박하는 자리다.
- **굵기 총합 = 전체 개수**가 된다.
- 비례이므로 「3배 많다 = 3배 굵다」가 **참**이 된다.

★그리고 **개수를 글로도 적는다**(「분자 3 개」). 굵기만으로는 몇 개인지 셀 수 없다.

### 색 규약
- 프로젝트에서 뜻이 굳은 색을 **자료에 쓰지 않는다** —
  파랑=UI 크롬 · 초록=정답/완료 · 빨강=오답 · 앰버=경고·문항 · **회색=기구**.
- 남는 자리: 보라 · 청록 · 자홍.
- **채도를 낮춰 「연하게」 하지 말 것** — 2026-08-26 교사: 「연보라로 하니 잘 안 보인다. **확 다른 색, 채도가 높은 색**으로.」
  (실측 기준: 최대 채널 − 최소 채널 ≥ 120. 옛 연보라 `#C9B6E8` 은 50 이었다.)
- **CSS 변수와 JS 상수를 손으로 맞춰야 한다.** 어긋나면 범례 글자와 그림의 색이 갈린다. **검사가 이 짝을 문다.**
- 밝은 색을 **글자에 그대로 쓰지 말 것** — `--n14-ink` 처럼 글자용 짙은 짝을 따로 둔다.
- ★**색만으로 구분시키지 않는다.** 진한 칸에 **흰 점**을 함께 찍는다(색각 이상·흑백 인쇄 대비).
  보라·청록은 2형 색각에서 가까워질 수 있다. 이 점을 빼지 말 것.

## 6. SVG 함정 (전부 실제로 겪었다)

| 함정 | 증상 | 규칙 |
|---|---|---|
| `<text>` 안의 `<sup>`·`<b>` | HTML 파서의 외래 콘텐츠 이탈로 **`<svg>` 가 통째로 닫혀 그림이 거기서 끊긴다** | 무대에서는 **유니코드 윗첨자**(`¹⁵N`). HTML 본문·표·문항에서는 `<sup>15</sup>N` |
| 회전 | 무대 한가운데를 축으로 크게 휘돈다 | **도는 `<g>` 와 자리 잡는 `<g>` 를 가른다** + `transform-box:fill-box` |
| `svg.stage{min-width:600px}` | `max-width` 를 이긴다(**min-width 가 더 세다**) — 그림이 칸 밖으로 빠져나간다 | 작게 넣는 자리에는 `min-width:0` 을 함께 |
| 눈금 이름과 값 라벨 | 같은 쪽에 두면 겹친다 | **눈금은 왼쪽, 값은 오른쪽**처럼 자리를 가른다 |
| 그룹마다 붙인 주석 | 그룹이 둘 이상인 국면에서 **왼쪽 글이 오른쪽 물체를 덮는다** | 글은 **국면마다 한 번만**. 자리는 빈 쪽에 |
| 그룹 간격 | 오른쪽 그룹의 왼쪽 정렬 라벨이 왼쪽 그룹 칸을 덮는다 | 라벨 폭만큼 벌린다(1-5 는 24px → 64px) |
| 스케일된 글자 | `scale(1.15)` 면 글자도 1.15배 — 무대 밖으로 잘린다 | 무대 폭 안에 들어오는지 **브라우저에서 실측**(↓ §8) |

## 7. 공통 기계 — 그대로 복제해 쓸 것

| 기계 | 요점 |
|---|---|
| **상태 저장** | `state` 통째로 localStorage 한 칸. **`seq` 를 올리고, 저장소의 seq 가 크면 덮지 않는다**(두 탭이 서로를 지운다) |
| **복원** | `freshState()` 가 정의한 **칸만** 복원한다 → 옛 칸이 되살아나지 않는다. 없는 이름·범위 밖 값은 걸러 낸다 |
| **복원 후 연출** | 무대는 **완료 국면**에서 시작한다. 새로고침이 결과를 도로 감추면 안 된다 |
| **섹션 잠금** | 🔴**두지 않는다**(2026-09-01 교사 결정). 카드는 처음부터 다 열려 있고 **서로를 막지 않는다.** ↓아래 절 |

## 9. ★브라우저 실측 — 헤드리스가 못 보는 것

CSS 누락·글자 겹침·무대 밖으로 잘림은 헤드리스로 안 잡힌다. **로컬 서버로 띄워 실측한다.**
(`file://` 은 브라우저 확장이 막는다. `python -m http.server 8765 --bind 127.0.0.1`)

### 재사용 — 모든 국면 × 모든 모델에서 글자 겹침·넘침 세기
```js
// ★전환을 먼저 꺼야 한다. 안 그러면 애니메이션 중간을 재서 거짓 양성이 쏟아진다.
const st = document.createElement('style');
st.textContent = '.rmove,.rfade{transition:none !important;}';
document.head.appendChild(st);
// ⚠ 나중에 지울 때 st.remove() 로 지울 것.
//   querySelectorAll('style') 을 훑어 지우면 본 스타일시트까지 지운다(실제로 겪었다).

function hits(sel){
  const svg = document.querySelector(sel); if (!svg) return [];
  const R = svg.getBoundingClientRect();
  const vis = e => { let n = e; while (n && n !== svg){ if (n.getAttribute && n.getAttribute('opacity') === '0') return false; n = n.parentElement; } return true; };
  const ts = [...svg.querySelectorAll('text')].filter(t => vis(t) && t.getBoundingClientRect().width > 0);
  const rs = [...svg.querySelectorAll('rect')].filter(r => vis(r) && r.getBoundingClientRect().width > 0);
  const ov = (a, b) => { const A = a.getBoundingClientRect(), B = b.getBoundingClientRect();
    return Math.min(A.right,B.right) - Math.max(A.left,B.left) > 3 &&
           Math.min(A.bottom,B.bottom) - Math.max(A.top,B.top) > 3; };
  const o = [];
  for (let i = 0; i < ts.length; i++){
    const b = ts[i].getBoundingClientRect();
    if (b.right > R.right + .5 || b.left < R.left - .5) o.push('밖으로 ' + ts[i].textContent.slice(0,14));
    for (let j = i+1; j < ts.length; j++) if (ov(ts[i], ts[j])) o.push('글✕글 ' + ts[i].textContent.slice(0,10));
    for (let k = 0; k < rs.length; k++)   if (ov(ts[i], rs[k])) o.push('글✕칸 ' + ts[i].textContent.slice(0,12));
  }
  return [...new Set(o)];
}
```
★`getCTM()` 으로 재지 말 것 — 뷰포트 배율이 섞여 엉뚱한 값이 나온다. **화면 좌표(`getBoundingClientRect`)로 잰다.**

### 그 밖에 실측할 것
- 문서 가로 스크롤(`scrollWidth > clientWidth`)
- 부모 밖으로 나간 `<svg>` (가로 스크롤 컨테이너는 뺀다)
- 아직 가로 스크롤이 남은 `.stage-wrap`·`.tbl-outer`
