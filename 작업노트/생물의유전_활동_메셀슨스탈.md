## 1. 이 활동이 노리는 것 한 가지

> **1회 복제만으로는 분산적 복제를 지울 수 없다.**

반보존적과 분산적은 **G1에서 똑같이** 중간 무게의 띠 하나를 예상한다. 두 모델을 가르는 것은 **2세대뿐**이다.
그래서 ④ 카드에 잠금을 박아 두었다.

```
G1 결과만 공개 → 「지금 지울 수 있는 모델은?」(정답: 보존적 하나뿐) → 답해야 G2 공개 단추가 열린다
              → G2 를 공개해야 c2·c3·c4 문항이 나온다
```

**이 차례가 깨지면 c1의 정답 근거가 무너진다.** 코드에서 두 겹으로 막아 두었다.
- `cmpReveal(2)` 는 `state.qPick['c1'] === undefined` 면 아무 일도 하지 않는다.
- `cmpQList()` 는 `cmpStage >= 2` 가 아니면 c1 하나만 내놓는다. **교사용 해제로도 앞당겨지지 않는다.**

## 2. 화면 구성

| # | 카드 | 학생이 하는 일 |
|---|---|---|
| ① | 복제모델은 셋이었다 | 세 모델 도해 카드 3장 + 「세 모델이 다른 점은?」 1문항 |
| ② | 무게를 재는 법 <span>밀도</span> | 위·아래 가닥을 골라 **네 조합**을 모두 만든다 → 저울 → 원심분리 연출 → 결론 3문항 |
| ③ | 세 모델을 직접 굴려 보시오 <span>예상</span> | 모델 칩을 골라 **셋을 모두 굴린다** → P·G1·G2 조성표 + 예상 띠 → 결론 3문항 |
| ④ | 실제 결과와 맞추어 보시오 <span>배제</span> | **한 세대씩** 공개 → 예상과 대조 → 판단 4문항 |
| 💪 | 더 풀어 보기 | 4문항(중 2 · 상 2). 풀지 않아도 활동은 완료된다 |
| ⑤ | 정리하기 | 서술형 3 + 창의력 1 + 자기평가 3줄. 모범답안은 자수를 채워야 열린다 |

**잠금 순서** = ② → ③ → ④ → 💪. 각 단계는 *조작을 다 하고 결론 문항에 답해야* 끝난다.
교사는 **진행 배지를 2.5초 안에 5번 탭**하면 전부 열린다(저장되지 않는다 — 새로고침하면 도로 잠긴다).

## 3. 설계에서 못 박은 것 (고치기 전에 읽을 것)

### ★띠는 그려 넣은 그림이 아니라 **계산된다**
분자 = 가닥 2개 → 가닥의 ¹⁵N 칸 수 → `f15` → 띠 높이 `34 + 60·f15`, 띠 굵기 `5 + 11·비율`.
화면의 모든 띠·이름·표가 이 한 값에서 파생된다. 그래서 「무거우면 아래」가 말이 아니라 기계다.

- **높이 = 밀도 / 굵기 = 양.** 절대 섞지 않는다. 섞으면 「굵으면 무겁다」 오개념을 앱이 스스로 심는다.
- **띠 색은 두 질소 색을 f15로 섞은 한 덩어리**로 그린다. **칸으로 쪼개 그리지 말 것** —
  쪼개면 「중간 띠 = 무거운 것과 가벼운 것이 반반 섞인 것」이라는 **최우선 오개념(M-01)** 을 앱이 심는다.
- **¹⁵N 칸 총합은 어느 모델·어느 세대에서나 언제나 16.** ¹⁵N 원자는 배지를 바꾼 뒤 늘지 않는다. 검사가 문다.
- 굵기에는 **배수를 쓰지 않는다.** 기본 굵기 5px 이 있어 굵기가 3배가 되는 일은 구조적으로 없다
  (보존적 G2 = 7.75 : 13.25 ≒ 1.7배). 배수는 **분자 개수**에만 쓴다.

### ★연출 엔진 — `aniLast` 는 상수가 아니라 **함수**다
1-4 의 `ANI_LAST` 는 상수 4였다. 그대로 복사하면 국면 6개짜리 무대가 4에서 멈춰 마지막 두 장면을 영영 못 본다.
→ `aniLast(st, id)` 로 바꿨다. cmp 무대는 **G1 공개 때 4국면 / G2 공개 때 6국면**이다 — 아직 안 본 장면을 미리 보여 주지 않는다.

### ★무대(SVG) 글자는 유니코드 윗첨자 `¹⁵N` 을 쓴다
`<sup>`·`<b>` 를 `<text>` 안에 넣으면 HTML 파서의 외래 콘텐츠 이탈 규칙이 `<svg>` 를 통째로 닫아 **그림이 거기서 끊긴다**(1-4 함정).
HTML 본문·표·문항에서는 `<sup>15</sup>N` 을 쓴다.

### ★회전은 도는 `<g>` 와 자리 잡는 `<g>` 를 가른다 + `transform-box:fill-box`
없으면 무대 한가운데를 축으로 크게 휘돈다(1-4 「원심분리가 안 보인다」의 원인).

### ★2단 배치 경계는 **1180px** · 좁은 화면은 `order` 로 「조작 → 자료 → 문항」 되세우기
1-4 §3-2 그대로. 1179px 로 정수로 끊지 않는다(1179~1180 사이 소수 폭이 두 규칙 어디에도 안 걸린다).

2. 「가벼운 띠가 **세 배 굵다**」 → 틀렸다. → 「가벼운 **DNA 가 세 배 많다**」로 고쳤다(`MODELS.cons.capG2`).

### ① ★애니메이션 — 「다시 그리기」에서 「이동」으로 (구조 변경)
chromolab(`/f/과학/생명과학/과학허브/chromolab`, React+framer-motion)이 하는 일은 하나다 —
**염색체마다 `key` 를 고정해 두고 `animate={{left,top}}` 로 위치만 바꾼다.** 그래서 미끄러진다.

이 무대는 국면마다 `setHTML('repStage', ...)` 로 **SVG 를 통째로 다시 그리고 있었다.**
새 노드는 전환 없이 나타나므로 분자가 「튀어나왔다」. 구조를 바꿨다.

| 무엇 | 어떻게 |
|---|---|
| `REP_CAST` | 모델마다 **[위 가닥 key, 아래 가닥 key]** 대본. 이 표가 무대의 전부다 |
| `repLayout(id, ph)` | 국면 → 가닥·라벨의 자리와 투명도를 계산하는 **순수 함수**(검사가 이걸 문다) |
| `repStageSvg(id)` | 무대를 **한 번만** 짓는다. 가닥마다 `<g id="rs_s_<key>">` |
| `repApplyPhase(id)` | 국면이 바뀌면 **transform·opacity 만** 바꾼다 |
| `repMounted` | 같은 모델이면 다시 짓지 않는다. **다시 지으면 애니메이션이 죽는다** |
| `.rmove` CSS | `transition:transform .85s ...` — framer-motion 자리를 CSS 가 맡는다 |

★**전환은 SVG `transform` 속성**에 건다(CSS transform 이 아니다). 속성에도 transition 이 걸린다.

그래서 학생이 눈으로 좇을 수 있다 —
- **반보존적**: 어버이 가닥 A·B 가 끝까지 살아남아 **서로 다른 딸 분자**로 갈라져 들어간다.
- **보존적**: A·B 가 **한 번도 떨어지지 않고** 짝을 유지한 채 내려간다.
- **분산적**: 어버이 가닥의 key 가 **이어지지 않는다**(조각나 정체가 사라진다).

지나간 세대는 **흐린 자취 + 점선 혈통선**(`repGhostSvg`)으로 남겨 가계도처럼 읽게 했다.
가닥이 아래로 이동해 버리므로 그것이 없으면 윗줄이 텅 빈다.

⚠ **가닥의 칸(H/L)은 `REP_CAST` 에 적지 않는다** — `MODELS` 에서 읽는다. 정본은 하나여야 한다.
검사가 「대본과 MODELS 가 일치하는가」·「같은 key 는 세대가 바뀌어도 칸이 같은가」를 문다.

### ② 조성표 — 오른쪽 칸에서 잘렸다
6열짜리 표가 **440px 오른쪽(조작) 칸**에 있어 「섞임」 열이 잘려 있었다.
표는 **자료**이므로 왼쪽 칸으로 옮겼다(2단 규약 그대로). 머리글에 색과 부제
(무거운 DNA / 중간 무게 / 가벼운 DNA / 가닥 안에서 섞임)를 붙이고, 0이 아닌 칸만 진하게,
지금 무대에 떠 있는 세대는 노랑 테두리로 짚는다.

### ③ ★띠 굵기 — 분율이 아니라 **분자 개수**에 비례한다
처음엔 `3 + 22·r`(분율)로 고쳤는데, **교사가 그 자리에서 오개념을 짚었다** —

> 「P세대 띠 1개의 굵기가 2세대 띠 1개보다 월등히 굵어서 더 그런 느낌이 든다.
> 차라리 **P세대 띠 1개의 굵기를 2세대 띠 1개랑 같게** 해야 오개념이 안 생기겠는데?」

맞는 지적이다. 분율로 그리면 P 의 띠(**분자 1개**, 25px)가 G2 의 띠(**분자 2개**, 14px)보다 굵다.
화면에는 「굵기 = 그 무게를 가진 DNA의 양」이라 써 놓고 **정반대를 보여 주고 있었다** —
앱이 스스로 오개념을 심는 상태였다.

→ **`bandT(n) = 6n`** (개수에 정비례). 그러자 세 가지가 한꺼번에 맞아떨어졌다.

| 맞아떨어진 것 | 값 |
|---|---|
| P 의 띠(1개) = 보존적 G2 의 무거운 띠(1개) | 둘 다 **6px** |
| 중간 무게의 띠는 세대가 지나도 굵기가 그대로 | G1 12px → G2 **12px** (분자가 늘 2개) |
| 한 시험관의 굵기 총합 = 그 세대의 분자 수 | P 6 · G1 12 · G2 **24** |

★세 번째가 특히 값지다 — **「중간 띠가 가늘어진다 = 수가 줄어든다」는 Q10 이 겨냥한 오개념을
그림이 스스로 반박한다.** 분율로 그렸을 때는 그림이 오히려 그 오개념을 뒷받침하고 있었다.
★비례이므로 「3배 많다 = 3배 굵다」가 **참**이 됐다(옛 식은 바닥값 때문에 거짓이었다).

이를 위해 **모든 띠 객체가 `n`(분자 개수)을 싣는다**(`bandsOf` · `REAL_BANDS` · ② 무대 · 문항 그림).
`REAL_BANDS` 의 n 은 **어버이 DNA 1개에서 출발**했을 때의 수다(1 → 2 → 4).
그리고 **띠마다 「분자 N 개」를 적었다** — 굵기만으로는 몇 개인지 셀 수 없다.
★최대 26 을 넘기지 말 것(시험관 아래 곡면 반지름이 26 이다). 검사가 문다.

> ⚠ **옛 검사는 이 잘못을 못 잡았다.** `rt > 2` 같은 「대략」 단언이라 옛 식으로도 통과했다.
> → 지금은 **규칙 자체**를 문다(`bandT(2) === 2·bandT(1)` · P 와 G2 의 1개 띠가 같은 굵기 ·
> 중간 띠 굵기 불변 · 굵기 총합 = 분자 수). 일부러 옛 식으로 되돌려 **실제로 잡히는지 확인했다.**

### ③-2 ★복제를 「① 분리 → ② 합성」 두 국면으로 (6국면 → 8국면)

> 「반보존적 복제 애니메이션에서 **각 주형 가닥이 나뉘어진 다음에 새 가닥이 합성되는
> 두 과정을 명백히 구분**시켜놓으면 좋겠다.」

한 국면에 두 사건을 넣으니 「갈라지는 것」과 「새로 만들어지는 것」이 뭉개져 있었다.
국면을 8개로 늘렸다 — `0 P · 1 배지교체 · 2 ①분리 · 3 ②합성 · 4 G1 · 5 ①분리 · 6 ②합성 · 7 G2`.

**분리 국면에는 그 세대의 새 가닥을 아예 그리지 않는다**(`repIsNewAt` 로 걸러 낸다).
덤으로 **보존적은 분리 국면에 아무것도 열리지 않는 것**이 그대로 보인다 — 그 모델의 요지다.
`repFrame` 이 `stage:'assembled'|'separate'|'synth'` 를 돌려주고, 검사가
「분리 국면에 새 가닥이 하나도 없다」·「합성 국면에서 가닥이 늘어난다」를 문다.

### ③-3 ★복제가 시작되면 그 세대의 「결과」 표시를 내린다

> 「세 모델 공통으로 4~5단계 사이가 어색하다. **1세대의 결과 그림과 설명이
> 1세대의 복제가 시작된 후에도 여전히 남아 있어서** 그런 것 같다.」

자취·혈통선·행 이름(G1·G2)을 **조립이 끝난 국면(4·7)에만** 보이게 했다(`REP_ASSEMBLED`).
복제 중(2·3·5·6)에는 전부 내린다. 예상 튜브와 조성표의 공개 시점도 `ph>=4` / `ph>=7` 로 옮겼다.

### ③-3-2 ★분산적만 이전 단계 그림이 남아 있었다

> 「분산적 모델 애니메이션에서는 여전히 이전 단계의 그림이 남아 있는 상태다.」

두 곳이 원인이었다.

| 무엇 | 왜 남았나 | 고친 것 |
|---|---|---|
| 분리 국면 | 어버이 분자를 **제자리에 그대로 남겨 두고** 그 위에 조각 구름을 덮어 그렸다 | 분산적은 조각나 **사라진다** → `repFrame` 이 빈 목록을 돌려준다 |
| 합성 국면 | 조각 구름을 **합성 국면까지** 그려 이어 붙은 분자 위에 겹쳤다 | 조각 구름은 **분리 국면에만**. 합성에는 이어 붙는 자리를 막대로 짚기만 |

★분리 국면에 **무엇이 남는가가 세 모델을 가르는 자리**다 — 이것이 이 무대의 요지가 됐다.

| 모델 | 분리 국면에 남는 것 |
|---|---|
| 반보존적 | 어버이 가닥 둘이 **갈라져** 딸 자리로 벌어진다 |
| 보존적 | 어버이 분자가 **열리지 않고 제자리에** 그대로 있다 |
| 분산적 | **아무것도 남지 않는다.** 조각 구름뿐이다 |

덤으로 조각의 조성을 **어버이에서 계산**하게 했다 — 어버이의 16칸이 그대로 흩어진 것이다.
P 를 자르면 16칸 모두 ¹⁵N, G1 을 자르면 두 무리에 8칸씩. **¹⁵N 칸 총합은 늘 16** 이다.
검사가 조각의 흰 점 개수를 세어 이것을 문다.

### ③-4 곁가지 — 캡션과 주석
- 마지막 국면 캡션 「무거운 하나, 가벼운 셋이다」가 어색하다는 지적 →
  「무거운 DNA 1개와 가벼운 DNA 3개가 되었다」로. 세 모델 모두 다시 썼다.

  왼쪽 그룹의 마지막 칸을 덮고 있었다. **좁히지 말 것.**
