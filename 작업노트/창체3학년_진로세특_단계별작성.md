## 방법 노하우 (재사용 가치)
1. **HWP→PDF 일괄 변환**: `pip install pyhwpx` → `Hwp(new=True, visible=False)` + `open()`/`save_as(dst, format="PDF")`. 한글(HWPFrame.HwpObject COM) 설치 필요. pyhwpx가 보안승인 팝업(FilePathCheckerModule.dll)을 자동 처리해서 headless 일괄변환 가능. 17건 전부 성공, 변환 PDF는 텍스트 레이어 살아있음(이후 파싱에 유리).
2. **스캔 워크시트(이미지 PDF) 판독**: get_text()가 빈 문자열 → PyMuPDF 2배율 렌더 → 스캔이 90° 돌아가 있으면 PIL `ROTATE_90`으로 보정(이 세트는 ROTATE_270이 아니라 ROTATE_90이 정방향) → 페이지당 1명 vision 판독(학번·이름이 우상단에 있어 자동 매칭 가능, 판독불확실 표시 포함).
3. **워크플로 중단 시 결과 회수**: 세션 사용량 한도로 에이전트가 무더기 실패해도, 완료분은 `subagents/workflows/<runId>/journal.jsonl`에 `{"type":"result",...}`로 남음 → 파싱해서 전량 회수 가능. 워크플로 resume(resumeFromRunId)은 **같은 세션에서만** 유효 — 새 세션 대비로는 journal 회수본을 폴더에 저장해두는 것이 정답.
4. 판독 에이전트가 이름을 오독해도(흘림체) 학번으로 명단 매칭하면 복구됨. 학번도 없으면 이름 별칭 사전으로 폴백.
