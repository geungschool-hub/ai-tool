# 융합과학탐구 — 후속 탐구 보고서 가이드 앱 (yoonghob-guide)

> 2026-08-12 제작·배포. **정본 PRD = `융합과학탐구/PRD_후속탐구가이드.md`** (범위·화면 설계·결정 사항 전부 여기).

## 무엇
- 3학년 융합과학탐구 2학기 수행평가 앱. **후속 탐구 보고서(수행② 50점) 전용** — 계획서(수행① 50점)는 교사가 별도 양식으로 직접(앱 범위 밖, 교사 결정 2026-08-12).
- 핵심 컨셉: **1학기 탐구의 아쉬운 점에서 다시 시작하는 보고서**. 서론에 "아쉬웠던 점", 고찰에 "아쉬운 점이 보완되었나"가 들어가게 틀에 박음.
- 1학기 report-guide(보고서작성법_가이드) 앱을 개조. 11화면→**5화면**(개관·재료→서론→본론→결론→점검·제출), 입력 9칸+제목. 관통 예시 = 카페인 후속 탐구(문헌 결론→우리 반 설문으로 직접 확인).
- 마지막 화면이 입력을 **보고서 한 편으로 취합** → [보고서 제출하기](Firebase) / PDF / 전체 복사. 체크리스트 10항목은 보완 확인형(자기점검용, 채점 비연계).

## Firebase (gongju7-vocab RTDB 공유 — 규칙 문서는 DB당 하나!)
- 제출 경로 **`yoonghobReports/{학번}`** = `{sid,name,title,answers,reportText,submittedAt,updatedAt}` · 무인증 공개 규칙(reportPlans와 동일 패턴).
- 규칙 배포 2026-08-12: `_firebase/gongju7-vocab/database.rules.json`에 경로 추가 → **README 절차대로 라이브 대조 후** deploy. 라이브 규칙은 콘솔 복사 대신 **CLI refresh_token→access_token→`/.settings/rules.json` REST**로 자동 취득 가능(1p1t 노트의 방법, 이 세션에서 실증. curl `--ssl-no-revoke` 필요 — python urllib는 학교망 SSL에 막힘).
- 배포 후 경로별 실측: yoonghobReports **200** / reportPlans 401 / vocab/config 401 / vote 200 (다른 앱 무영향). REST PUT/DELETE 왕복 성공.
- ⬜ **브라우저 실기 왕복(학생 제출→admin 수신)은 교사가 확인해야 함** — 샌드박스에선 firebasedatabase.app SSL로 SDK 실사용 검증 불가(1학기와 동일).

## 운영 스위치·함정
- 마감: index.html의 **`REPORT_CLOSED`** 플래그 하나(true=마감, 재배포 필요). 마감일은 앱에 안 박음(목표 8/31 이전, 교사 구두 독려).
- localStorage 키: 학생 `yoonghob_report_v1` · 안내바 `yoonghob_a2hs` · 온보딩 `yoonghob_intro` — 1학기 앱(`bogoseo_*`)과 충돌 없음.
- 제출 12초 타임아웃(학교망 필터로 버튼 고착 방지) · 학번 5자리 검증(confirm) 들어 있음.
- 검증 완료: 임베드 JSON 파싱 / 인라인 JS `node --check`(index·admin) / Edge 헤드리스 스샷(1·5화면 — 우측 잘림은 최소창폭 아티팩트 오탐, [[ref_edge_headless_min_window]]).
- ★콘솔 출력 cp949 함정 재확인 — python 검증 스크립트는 `sys.stdout.reconfigure(encoding='utf-8')` 필수.
- `융합과학탐구/_제출데이터/`(1학기 계획서 사본, **전원 2학년 학번 = 이번 3학년 데이터 아님**·실명 포함)는 .gitignore 등록 완료. 향후 보고서 제출 백업도 이 폴더에.

## 남은 것
1. 교사: 라이브에서 왕복 제출 테스트(제출→admin 수신→삭제) + admin 비밀번호 최초 설정

3. 교사: 계획서(수행①) 양식 별도 제작 — 앱 1번 화면의 세 칸(1학기 요약/아쉬운 점/후속 질문)과 이어지게 하면 좋음
4. 학기 끝나면: `REPORT_CLOSED=true` 재배포 + 제출 데이터 CSV/JSON 백업(`융합과학탐구/_제출데이터/`) + 규칙 `yoonghobReports` false로 닫기(README 절차)
